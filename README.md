**THE MISSING FLOOR**

## 어떤 게임인가요

1인칭 한국 생활공포입니다. 서류에 없는 층이 있는 빌라 403호로 이사 온 뒤,
매일 새벽 4시 30분부터 5시 30분까지 건물에 갇혀 그 층의 정체를 조사합니다.

같은 층에 눈이 없는 것이 하나 있습니다. 대신 아주 잘 듣습니다.
발소리, 문 여는 소리, 서랍 소리, 겁에 질렸을 때의 심장 소리까지.
**그래서 이 게임의 조작은 "어떻게 싸울까"가 아니라 "얼마나 조용히 할까"입니다.**

무기는 없습니다. 체력 바도 없습니다. 대신 계량기와 검침 기록지,
민원 대장과 먹지가 있습니다.

게임 전체는 이사 온 **저녁의 입주**에서 시작합니다. 짐을 풀고 눕고 나면
첫 밤이 열립니다.

계약서, 반송 소포, 조율 수첩은 장식이 아니라 같은 주소의 모순을 서로 다른
방식으로 보여 주는 첫 단서입니다. 글자를 읽고 직접 건물 동선을 확인해야
다음 밤의 퍼즐이 이해됩니다.

| | |
|---|---|
| **장르** | 1인칭 생활공포 · 은신 · 조사 |
| **플레이 방식** | 소리 관리, 기록 대조, 회피 |
| **한 회차 분량** | 프리뷰 기준 약 2~3시간 |
| **배경** | 공식 기록은 4층, 옥상에는 미등록 공간이 있는 붉은 벽돌 빌라 |
| **현재 상태** | Windows 개발 프리뷰 (밤 1~4 + 결말 3종) |

> 아래 화면은 전부 실제 플레이 빌드에서 찍었습니다. 스톡 이미지나 컨셉아트가
> 아닙니다. 대신 조명·모델·믹스는 아직 다듬는 중이라 최종 품질은 아닙니다.

## 규칙은 세 개뿐입니다

### 1. 그는 보지 못합니다. 듣습니다

노크 세 번, 그리고 귀를 기울이는 몇 초. 이 박자가 이 게임의 메트로놈입니다.
**그가 두드릴 때 움직이고, 그가 들을 때 멈추세요.**

한 번 난 소리는 "무슨 소리지" 정도로 끝납니다. 같은 자리에서 두 번 나면
"누가 있다"가 됩니다. 그때부터 달려옵니다.

### 2. 모든 소리에는 크기가 있습니다

문을 길게 눌러 천천히 열면 조용하고, 짧게 탭으로 당기면 빠르지만 건물이 듣습니다.
숫자도 게이지도 없습니다. 대신 방금 낸 소리가 어디까지 퍼졌는지를 파문 링이 보여 줍니다.

![소음 파문 링이 표시된 4층 복도 실제 게임 화면](Docs/Media/readme/hud-noise-ripple.webp)

<sub>파문의 반지름이 곧 "그가 들을 수 있는 거리"입니다. 벽 하나를 넘으면 줄고, 층을 넘으면 더 줄어듭니다.</sub>

발밑도 규칙입니다. 장판과 옥상 방수층은 조용하고, 철제 계단은 길게 울립니다.
5층의 석고 파편과 밤 4의 고인 물은 걷기만 해도 크게 들립니다.
같은 속도로 걸어도 어느 바닥을 고르느냐에 따라 들리는 거리가 달라집니다.

## 네 번의 밤, 네 개의 다른 규칙

| 밤 1 · 소리 | 밤 2 · 기록 | 밤 3 · 조율 | 밤 4 · 대답 |
|:---:|:---:|:---:|:---:|
| 규칙을 몸으로 배웁니다 | 종이의 모순을 찾습니다 | 벽 뒤의 것을 특정합니다 | 가장 큰 소리를 내야 합니다 |

같은 건물을 밤마다 다른 방식으로 읽게 됩니다. 밤 1에서 배운 소리 규칙이
밤 2의 기록 대조를 가능하게 하고, 그 둘이 밤 3의 벽 앞에서 하나로 이어집니다.
그리고 밤 4에서는, 지금까지 배운 것을 전부 뒤집어야 합니다.

## 처음 켜면

곧바로 본편으로 들어가지 않습니다. 첫 실행에서는 헤드폰 플레이를 한 번 권한 뒤,
실제 위층 노크 소리로 음량과 어두운 곳의 경계를 함께 맞춥니다.

![첫 실행 소리와 밝기 보정 화면 실제 게임 화면](Docs/Media/readme/m65-first-run-audio-calibration.webp)

<sub>노크가 <b>겨우</b> 들리면서 위쪽에서 온다고 느껴질 때까지 올리고, 가운데 계조만 겨우 보이도록 밝기를 맞추면 됩니다. 2분이면 끝납니다.</sub>

이 게임에서 노크와 배관음은 분위기용 배경음이 아니라 **위·아래·뒤를 구분하는
길 찾기 정보**입니다. 그래서 헤드폰을 권합니다. 스피커도 막지 않고,
보정값은 진행이나 결말 조건에 영향을 주지 않습니다.

그리고 실제 시각 04:30~05:30 사이에 타이틀을 켜 두면, 멀리서 난 노크가
한 사이클 뒤에 대답을 받습니다.

## 조작

| 입력 | 동작 | 입력 | 동작 |
|---|---|---|---|
| `W A S D` | 이동 | 마우스 | 시점 |
| `왼쪽 Shift` | 달리기 | `C` | 앉기 |
| `Space` | 낮게 뛰기 |  |  |
| `E` | 조사 · 상호작용 | `E` 길게 | 조용히 열기 · 벽에 귀 대기 |
| `Q` | 문 두드리기 | `왼쪽 Ctrl` | 숨 참기 |
| `F` | 손전등 | `H` | 단계별 힌트 |
| `Tab` | 지금 들리는 것들 | `F9` | 최근 자동 저장 복원 |
| `F10` | 접근성 설정 | `Esc` | 일시정지 · 뒤로 |

문과 서랍은 **길게 눌러 천천히** 열면 조용하고 짧게 누르면 빠릅니다.
어느 쪽을 고를지는 그가 지금 어디 있느냐에 달렸습니다.

Xbox 배열 게임패드는 `A` 조사, `B` 노크, `L3` 달리기, `R3` 앉기,
`LB` 낮게 뛰기, `RT` 엿듣기, `LT` 숨 참기입니다. 실내 도약은 높이를
낮췄고, 세게 착지하면 실제로 소음이 발생합니다.

## 직접 해 보기

완성 배포판이 아니라 **소스에서 직접 빌드하는 개발 프리뷰**입니다.

| 필요한 것 | 버전 |
|---|---|
| OS | Windows 10 / 11 (64비트) |
| 엔진 | Unreal Engine 5.8 |
| 빌드 도구 | Visual Studio 2026 — `Game development with C++` 워크로드 |
| 저장소 | Git + Git LFS (에셋이 LFS에 있습니다) |
| 권장 | 헤드폰. 진심으로 권합니다 |

```powershell
git clone https://github.com/easygap/Indie-Game.git
cd Indie-Game
git lfs pull
.\Scripts\RunGame-MissingFloor.bat
```

`RunGame-MissingFloor.bat`은 입주 첫날 저녁부터 시작합니다. 계약서와 반송 소포를
확인하고 이웃·편의점·옥상 문을 둘러본 뒤 잠들면, 새벽 4시 30분의 첫 밤과
계량기·먹지 퍼즐, 낮/밤 순환으로 이어집니다.
에디터로 열려면 `Scripts\RunEditor.bat`을 쓰세요.

## 플레이 전에 알아 두실 것

- 포획 후 암전, 갑작스러운 접근, 화면 흔들림과 점멸이 있습니다.
  흔들림·점멸은 접근성 설정에서 줄일 수 있습니다.
- 장기간 은폐된 유해를 연상시키는 시각 요소가 나옵니다. 직접적인 신체 훼손 묘사는 없습니다.
- 층간소음, 무단증축, 산업재해 은폐 같은 현실 소재를 다룹니다.
  실제 사건이나 인물과는 무관합니다.
- 소리가 게임의 절반입니다. 무음으로는 사실상 플레이가 어렵습니다.

## 자주 받는 질문

**전투가 있나요?**
없습니다. 무기도, 체력도, 격투도 없습니다. 할 수 있는 건 조용히 있기,
숨 참기, 소리로 유도하기, 그리고 기록을 읽는 것입니다.

**잡히면 처음부터 다시 해야 하나요?**
아닙니다. 같은 밤 04시 30분의 침대로 돌아오고, 알아낸 건 전부 유지됩니다.

**공략 없이 풀 수 있나요?**
그렇게 만들었습니다. 막히면 `H`로 단계별 힌트를 볼 수 있는데, 답을 알려 주지 않고
**어디를 봐야 하는지**만 알려 줍니다. 다섯 번 잡히면 힌트를 요청하지 않아도
게임이 먼저 도와줍니다.

**세이브는 어떻게 되나요?**
밤 시작과 주요 분기에서 자동 저장됩니다. `F9`로 가장 최근 자동 저장으로
돌아갈 수 있습니다.

**마이크를 정말 쓰나요?**
쓸 수 있지만 기본값은 꺼져 있습니다. 켜면 실제 방의 소음이 게임 안 소음에
더해집니다. 음성이나 파형은 저장도, 전송도 하지 않습니다.

**한국어만 있나요?**
지금은 그렇습니다. 음성은 없고 전부 자막입니다.
