# 없는 층

연락이 끊긴 오빠를 찾아 이사 온 달빛빌라.
반송된 소포에 적힌 주소는 **501호**. 그런데 이 건물은 4층까지밖에 없습니다.

낮에는 동네를 돌아다니며 단서를 찾고, 밤에는 소리를 따라오는 적을 피해
빌라를 조사하는 **1인칭 공포 게임**입니다.

싱글플레이 · 한국어 · Windows PC

## 낮에는 오빠를 찾습니다

주인공 유담은 403호에 짐을 풀고 이웃들에게 오빠의 소식을 묻습니다.
옆집에 들르고, 골목을 둘러보고, 편의점 직원과 이야기를 나눠 보세요.
집 안에 남은 물건과 사람들이 기억하는 일을 하나씩 확인해 나갑니다.

## 밤에는 소리를 조심하세요

새벽 네 시 반, 천장에서 노크 소리가 들립니다.
공동현관은 잠겨 있고 복도에는 소리를 듣고 다가오는 적이 있습니다.
뛰거나 문을 급하게 열면 들킬 수 있습니다. 문을 천천히 열고,
가까워지는 발소리를 들으며 움직이세요. 잠깐 숨을 참을 수도 있습니다.

![복도에서 다가오는 적과 붙잡히는 장면. 실제 게임 플레이](Docs/Media/readme/night-listener-chase.gif)

## 빌라에 무슨 일이 있었을까요?

관리실의 서류와 CCTV, 이름 없는 계량기에서 단서를 찾습니다.
문서를 읽고 벽 너머의 소리를 들어 보세요. 낮에 들었던 말이
밤에 발견한 흔적과 맞지 않을 때도 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` · 마우스 | 이동 · 둘러보기 |
| `왼쪽 Shift` · `C` · `Space` | 달리기 · 앉기 · 점프 |
| `E` | 조사 · 상호작용 |
| `E` 길게 | 문을 조용히 열기 · 벽에 귀 대기 |
| `Q` · `왼쪽 Ctrl` | 두드리기 · 숨 참기 |
| `F` | 손전등 |
| `F1` | 목표와 조작법 다시 보기 |
| `Tab` · `H` | 기록 보기(낮) · 힌트 |
| `← →` · 마우스 휠 | 문서 페이지 넘기기 |
| `Esc` · `F10` | 일시정지 · 접근성 설정 |

게임패드도 지원합니다. 설정에서 키와 버튼을 바꿀 수 있습니다.
조작 안내는 `F1`로 다시 열고 닫습니다. 게임패드에서는 십자키 위쪽입니다.
진행은 자동으로 저장되며, 다음에 실행할 때 **이어하기**로 계속할 수 있습니다.

## 접근성

`F10`으로 난이도와 자막, 소리 안내, 조작 도움을 설정합니다.

- **쉬움 / 보통 / 어려움 / 추격 없음**을 플레이 도중에도 바꿀 수 있습니다.
  ‘추격 없음’에서는 적에게 쫓기거나 붙잡히지 않습니다. 모든 퍼즐과 결말을 볼 수 있습니다.
- 자막 크기와 표시 시간, 배경 진하기를 조절할 수 있습니다.
- 소리가 나는 방향과 노크를 화면이나 게임패드 진동으로 확인할 수 있습니다.
- 카메라 흔들림과 빛 깜빡임을 줄일 수 있습니다.
- 길게 누르는 조작은 한 번 눌러 시작하고 다시 눌러 취소하도록 바꿀 수 있습니다.

갑자기 다가오는 적과 큰 소리, 어두운 장면이 나옵니다.
처음 실행할 때 편한 소리 크기와 밝기로 맞춰 주세요.
헤드폰과 스피커를 선택하고 배경 음악과 환경음도 따로 조절할 수 있습니다.

![자막 크기, 배경 진하기와 표시 영역을 조절하는 실제 설정 화면](Docs/Media/readme/settings-accessibility-20260922.webp)

## 직접 해 보기

ZIP 파일을 받아 압축을 모두 푼 뒤 `IndieGame.exe`를 실행하세요.

플레이 중 문제가 생기면 [이슈](https://github.com/easygap/Indie-Game/issues)에
어디서 무엇을 하다가 생겼는지 남겨 주세요. 화면 캡처가 있으면 확인하기 쉽습니다.
