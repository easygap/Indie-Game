## 밤에는 발소리 하나도 조심해야 합니다

공동현관이 잠기고, 복도에는 소리를 따라오는 것이 나타납니다.
문을 급하게 열거나 뛰면 위치를 들킬 수 있습니다.
벽에 귀를 대고, 가까워지는 소리를 듣고, 잠깐의 틈을 기다려 움직여야 합니다.

노크가 멎었다고 안전한 것은 아닙니다. 문을 천천히 열거나 숨을 참는 짧은 선택이
복도를 무사히 건널 수 있을지 결정합니다.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` · 마우스 | 이동 · 둘러보기 |
| `왼쪽 Shift` · `C` · `Space` | 달리기 · 앉기 · 낮게 뛰기 |
| `E` | 조사 · 상호작용 |
| `E` 길게 | 문을 조용히 열기 · 벽에 귀 대기 |
| `Q` · `왼쪽 Ctrl` | 두드리기 · 숨 참기 |
| `F` | 손전등 |
| `F1` | 목표와 조작법 다시 보기 |
| `Tab` · `H` | 기록 보기(낮) · 힌트 |
| `← →` · 마우스 휠 | 펼친 문서의 페이지 넘기기 |
| `Esc` · `F10` | 일시정지 · 접근성 설정 |

안내가 사라진 뒤에는 `F1`로 다시 볼 수 있습니다. 한 번 더 누르면 닫힙니다.
게임패드에서는 십자키 위쪽입니다. 키와 버튼은 설정에서 바꿀 수 있습니다.
진행은 자동으로 저장되며, 타이틀 화면의 **이어하기**로 돌아올 수 있습니다.

## 접근성

`F10`에서 자막과 문서 글씨 크기, 자막 배경, 소리 방향 표시,
카메라 흔들림과 점멸을 조절할 수 있습니다. 길게 누르는 조작은 대체 입력도 지원합니다.
게임패드로 문서를 읽을 때는 십자키 좌우로 페이지를 넘깁니다.

추격이 부담스럽다면 **조용한 밤**, 붙잡히지 않고 조사하고 싶다면
**듣기만 하는 밤**을 선택하세요. 플레이 도중에도 바꿀 수 있습니다.

갑자기 다가오는 적과 큰 소리, 어두운 장면이 나옵니다.
시작할 때 소리와 밝기를 맞춰 주세요. 헤드폰과 스피커에 맞는 출력 방식을 고를 수 있고,
음악과 환경음의 크기도 따로 조절할 수 있습니다.

## 직접 해 보기

현재 개발 중이며, 다운로드해서 바로 실행할 수 있는 배포판은 아직 없습니다.

[소스에서 실행하는 방법](Docs/PLAYING.md)에 준비부터 시작까지 정리해 두었습니다.

어디서 무엇을 하다가 생겼는지 남겨 주세요. 화면 캡처가 있으면 확인하기 쉽습니다.
