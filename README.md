# 없는 층

> 이 빌라는 4층까지다. 등기부에도, 관리대장에도, 구청 기록에도.
> 그런데 매일 새벽 네시 반, 꼭대기층 천장에서 노크 소리가 난다.

![새벽의 4층 복도를 기어 오는 위층 사람 실제 게임 화면](Docs/Media/night1-listener-corridor.png)

**없는 층**은 소리로 사냥하는 존재와 한 건물에 갇혀, 서류에 존재하지
않는 층의 진실을 밤마다 조사하는 1인칭 한국 생활공포 게임입니다.
당신이 내는 모든 소리 — 발소리, 문소리, 심지어 겁에 질린 심장 소리 —
가 그것을 부릅니다.

| 장르 | 플레이 | 배경 | 엔진·플랫폼 |
|:---:|:---:|:---:|:---:|
| 1인칭 생활공포 · 은신 | 조사 · 추론 · 회피 | 한국의 오래된 빌라 | Unreal Engine 5.8 · Windows |

> 아래 화면은 개발 중인 그레이박스 빌드의 실제 캡처입니다. 형체와
> 공간은 완성 아트가 아니라 현재 플레이 그대로의 모습입니다.

## 그는 보지 못한다. 듣는다

![소리를 따라 다가와 붙잡는 위층 사람과 네시 반의 침대로 되돌아가는 실제 플레이](Docs/Media/night-listener-chase.gif)

<sub>소리를 두 번 들려주면 달려듭니다. 잡히면 죽지 않습니다 — 새벽 네시 반의 침대에서 다시 눈을 뜹니다. 그리고 그는 조금 더 성급해집니다.</sub>

위층 사람은 눈이 없습니다. 노크 세 번, 그리고 귀를 기울이는 몇 초.
그 박자가 이 게임의 메트로놈입니다. **그가 두드리는 동안 움직이고,
그가 들을 때 멈추세요.** 냉장고나 배전반의 기계 소리 곁에서는 작은
소리가 묻힙니다. 공포에 심장이 뛰기 시작하면 — 그 소리도 그에게
들립니다.

소리에는 크기가 있습니다. 문을 홀드로 천천히 열면 조용하고, 탭으로
당기면 건물이 듣습니다. 화면 가장자리의 파문 링이 방금 낸 소리가
얼마나 멀리 퍼졌는지 보여 줍니다 — 숫자도, 게이지도 없습니다.

![복도 소화기가 떨어지는 순간의 실제 플레이](Docs/Media/night1-extinguisher-drop.gif)

<sub>떨어진 소화기 소리는 복도 전체에 퍼집니다. 그리고 그것이 소리를 확인하러 옵니다.</sub>

그 시간 동안 공동현관도 창문도 열리지 않고, 휴대폰은 신호를 잃고,
엘리베이터는 죽습니다. 밤의 무대는 건물 안입니다. 밤의 목표를 이루면
아침이 옵니다 — 낮은 안전합니다. 조사하고, 이웃에게 묻고, 침대에
누우면 다음 밤이 시작됩니다.

정답을 알려 주는 화면은 없습니다. 계량기의 죽은 바늘과 검침 기록지의
빈칸, 민원 대장의 볼펜 자국과 먹지의 눌린 글씨 — 서로 다른 두 기록이
같은 것을 가리킬 때에만 진실이 됩니다. 그리고 조사에는 값이 있습니다.
먹지를 문지르는 소리도, 두꺼비집을 올리는 소리도, 그가 듣습니다.

## 네 번의 밤

| 밤 1 · 소리 | 밤 2 · 기록 | 밤 3 · 조율 | 밤 4 · 대답 |
|:---:|:---:|:---:|:---:|
| 규칙을 몸으로 배운다 | 종이의 모순을 찾는다 | 벽 뒤의 것을 특정한다 | 가장 큰 소리를 내야 한다 |

지금 빌드에서는 밤 1과 밤 2를 플레이할 수 있습니다. 밤 3 — 서류에
없는 층으로 올라가는 밤 — 은 개발 중입니다.

## 조작

| 입력 | 동작 | 입력 | 동작 |
|---|---|---|---|
| `W A S D` | 이동 | 마우스 | 시점 |
| `E` | 조사·상호작용 | `E` 길게 | 조용히 열기·집중 조사 |
| `F` | 손전등 | `H` | 단계별 힌트 |
| `F9` | 최근 자동 저장 | `F10` | 접근성 설정 |
| `Esc` | 일시정지·뒤로 | `Enter` | 메뉴 선택 |

문과 서랍은 **길게 눌러 천천히** 열면 조용하고, 짧게 누르면 빠르지만
소리가 납니다. 어느 쪽을 고를지는 그가 어디 있느냐에 달렸습니다.

## 개발 프리뷰 실행

필요한 환경은 **Windows 10/11**, **Unreal Engine 5.8**,
**Visual Studio의 Game development with C++ 워크로드**입니다.

```powershell
git clone https://github.com/easygap/Indie-Game.git
cd Indie-Game
git lfs pull
.\Scripts\RunGame-MissingFloor.bat
```

`RunGame-MissingFloor.bat`이 없는 층의 밤 무대(위층 사람, 그 시간
봉쇄, 계량기·먹지 퍼즐, 낮/밤 순환)를 실행합니다. 에디터에서 열려면
`Scripts\RunEditor.bat`을 사용하세요.

정적 계약만 확인하는 명령:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Scripts\Validate-Project.ps1
```

> 현재 저장소는 개발 프리뷰입니다. 공간과 형체는 그레이박스이고, 밤
> 3~4와 조명·사운드 연출 패스는 진행 중입니다. 자동 검증은 서사 상태,
> 진실 교차, 저장·복원, UI·오디오 계약과 빌드 하네스를 다룹니다.
