# 없는 층

1인칭 공포 · 싱글플레이 · 한국어 · Windows

연락이 끊긴 오빠를 찾아 달빛빌라 403호로 이사 왔습니다.
오빠의 소포에 적힌 주소는 501호인데, 이 빌라는 4층까지입니다.
이사 첫날 밤, 천장에서 들리는 노크 소리에 잠이 깹니다. 새벽 네 시 반입니다.

![403호 앞 복도. 닫힌 현관문들이 늘어서 있고 바닥에는 끌린 자국이 남아 있다](Docs/Media/readme/prologue-corridor.webp)

## 이사 온 동네에서

짐을 풀고, 이웃집 문을 두드리고, 골목 끝 편의점에 들릅니다.
오빠를 아는 사람이 있는지 물어보고, 방에 가져온 짐에서 마지막 행적을 찾아봅니다.
빌라와 편의점 사이에는 상가 샛길과 뒤편 골목도 이어져 있습니다.

## 새벽에는 소리를 조심해야 합니다

새벽 네 시 반이 되면 공동현관이 열리지 않습니다. 복도에는 소리를 따라오는 것이 있습니다.
뛰거나 문을 급하게 열면 위치를 들킬 수 있습니다. 문을 천천히 열고,
벽에 귀를 대고, 가까워지는 발소리를 들으며 빠져나갈 길을 찾아야 합니다.

![어두운 복도에서 추적자가 다가와 플레이어를 붙잡는 장면](Docs/Media/readme/night-listener-chase.gif)

<sub>실제 플레이 화면입니다. 추격과 붙잡히는 장면이 나옵니다.</sub>

## 무슨 일이 있었는지 알아내기

관리실에 남은 기록을 읽고, 계량기와 전원을 확인하고, 이웃의 말을 대조합니다.
읽은 내용과 직접 본 것이 맞는지 확인해야 퍼즐을 풀 수 있습니다.
조사하다 막히면 `H`로 힌트를 볼 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` · 마우스 | 이동 · 둘러보기 |
| `왼쪽 Shift` · `C` · `Space` | 달리기 · 앉기 · 낮게 뛰기 |
| `E` | 조사 · 상호작용 |
| `E` 길게 | 문을 조용히 열기 · 벽에 귀 대기 |
| `Q` · `왼쪽 Ctrl` | 두드리기 · 숨 참기 |
| `F` | 손전등 |
| `Tab` · `H` | 기록 보기(낮) · 힌트 |
| `Esc` · `F10` | 일시정지 · 접근성 설정 |

게임패드도 지원합니다. 키와 버튼은 설정에서 바꿀 수 있습니다.
진행은 자동으로 저장되며, 다시 실행한 뒤 타이틀 화면에서 이어 할 수 있습니다.

## 접근성

`F10`에서 자막 크기와 배경, 소리 방향 표시, 카메라 흔들림과 점멸을 조절할 수 있습니다.
길게 누르는 조작이 불편하면 대체 입력을 켤 수 있습니다.

추격이 부담스럽다면 **조용한 밤**, 붙잡히지 않고 조사하고 싶다면
**듣기만 하는 밤**을 고를 수 있습니다. 난이도는 도중에도 바꿀 수 있습니다.

갑자기 다가오는 적과 큰 소리, 어두운 장면이 나옵니다.
시작할 때 소리와 밝기를 맞춰 주세요. 발소리와 노크가 들려오는 방향이 조사에 도움이 됩니다.
