# Missing Floor

반송된 택배에 적힌 오빠의 주소는 달빛빌라 501호.
그런데 이 건물은 4층까지다.

연락이 끊긴 오빠를 찾으러 낡은 빌라에 이사 온 유담의 이야기입니다.
이웃에게 소식을 묻고, 남겨진 물건을 살펴보세요.
새벽 네 시 반이 되면 천장에서 노크 소리가 들립니다.

Windows PC · 1인칭 공포 · 싱글플레이 · 개발 중

## 달빛빌라 403호

반송된 택배와 오래된 음성 메시지. 오빠를 찾을 실마리는 이삿짐 상자 안에 있습니다.
짐을 풀고, 옆집에 인사하고, 골목 건너 편의점에 들르세요.
누군가는 오빠를 기억하고 있을지도 모릅니다.

## 새벽 네 시 반

밤에는 소리에 반응하는 귀신이 복도를 돌아다닙니다.
뛰어가는 발소리, 급하게 여는 문소리에도 다가옵니다.
문을 천천히 열고, 가까이 지나갈 때는 잠깐 숨을 참으세요.

![불이 꺼진 복도. 문 아래로 이웃집 불빛이 새어 나온다.](Docs/Media/readme/game-corridor-night.webp)

붙잡히면 방에서 다시 눈을 뜹니다. 알아낸 단서는 남지만, 시간은 되돌아가지 않습니다.

[복도 추격 장면 · GIF](Docs/Media/readme/night-listener-chase.gif)

## 벽 너머의 소리

관리실 장부와 CCTV에는 서로 맞지 않는 기록이 남아 있습니다.
문서를 읽고, 계량기를 확인하고, 벽에 귀를 대 보세요.
읽은 기록은 낮에 `Tab`으로 다시 볼 수 있습니다. 막히면 `H`로 힌트를 확인하세요.

## 다운로드

현재 공개 버전은 **플레이 테스트 0.2.0**입니다. 아직 개발 중이며 무료로 받을 수 있습니다.

1. [Windows용 ZIP 파일](https://github.com/easygap/Missing-Floor/releases/download/v0.2.0/MissingFloor-0.2.0-Windows.zip)을 받으세요.
2. 압축을 모두 풀고 `MissingFloor.exe`를 실행하세요.
3. **게임 시작**을 누르세요. 저장된 진행이 있다면 **이어하기**로 계속할 수 있습니다.

진행 상황은 자동으로 저장됩니다. 실행 파일 옆의 `Engine`, `IndieGame` 폴더도 함께 있어야 합니다.
실행 방법과 확인된 PC 사양은 [실행 안내](Docs/PLAYING.md)에 정리했습니다.

게임은 **한국어·영어·일본어·중국어 간체·번체**를 지원합니다.
처음에는 Windows 언어를 따르며, 설정에서 바꿀 수 있습니다. 이 페이지의 언어 선택은 소개 문서만 바꿉니다.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` · 마우스 | 이동 · 둘러보기 |
| `왼쪽 Shift` · `C` · `Space` | 달리기 · 앉기 · 점프 |
| `E` | 물건 살펴보기 · 문 열기 |
| `E` 길게 | 문을 조용히 열기 · 벽에 귀 대기 |
| `Q` · `왼쪽 Ctrl` | 두드리기 · 숨 참기 |
| `F` | 손전등 |
| `F1` | 목표와 조작법 |
| `Tab` · `H` | 기록 보기(낮) · 힌트 |
| `← →` · 마우스 휠 | 문서 페이지 넘기기 |
| `Esc` · `F10` | 일시정지 · 접근성 설정 |

게임패드도 지원합니다. 키와 버튼은 설정에서 바꿀 수 있습니다.

## 난이도와 설정

추격이 부담스럽다면 `F10`에서 **추격 없음**을 고르세요.
귀신에게 붙잡히지 않고 이야기와 퍼즐을 진행할 수 있습니다. 어느 난이도에서도 모든 결말을 볼 수 있습니다.

자막 크기와 배경 진하기, 소리 방향 표시, 화면 흔들림과 조명 깜빡임을 조절할 수 있습니다.
길게 누르기가 불편하면 한 번 눌러 시작하는 방식으로 바꿔 보세요.

![자막과 조작 방식을 바꿀 수 있는 접근성 설정](Docs/Media/readme/settings-accessibility-20260929.webp)
