**THE MISSING FLOOR**

> 이 빌라는 4층까지다. 등기부에도, 관리대장에도, 구청 기록에도.<br>

## 어떤 게임인가

서류상 4층까지인 빌라의 403호로 이사 오면서 시작하는 1인칭 한국 생활공포입니다.
매일 새벽 4시 30분이 되면 한 시간 동안 건물에 갇히고, 그 사이에 없는 층의
정체를 조사하게 됩니다.

건물 안에 눈이 없는 것이 하나 있습니다. 대신 잘 듣습니다. 발소리, 문 여닫는
소리, 서랍 소리, 겁먹었을 때 심장 뛰는 소리까지 듣습니다. 무기도 체력 바도
없습니다. 가진 건 손전등 하나와 건물에 남아 있는 종이 기록들뿐입니다.

![소리를 따라온 위층 사람에게 붙잡히고 같은 밤 04시 30분의 침대로 돌아오는 장면](Docs/Media/readme/night-listener-chase.gif)

<sub>소리를 두 번 들려주면 달려옵니다. 한 번은 그냥 지나갑니다. 이 차이 하나로 게임 전체가 굴러갑니다.</sub>

| | |
|---|---|
| 장르 | 1인칭 생활공포 · 소리 은신 · 조사 추리 |
| 플레이 방식 | 소리 관리, 기록 대조, 회피 |
| 한 회차 분량 | 첫 결말까지 한 시간 반 안팎 |
| 결말 | 3종 |
| 언어 | 한국어 자막, 음성 없음 |
| 실행 환경 | Windows 10/11 · Unreal Engine 5.8 |
| 현재 상태 | 개발 프리뷰 — 프롤로그와 밤 1~4까지 |

## 어떻게 하는 게임인가

### 상대는 소리로 찾아옵니다

노크 세 번, 그리고 귀를 기울이는 몇 초. 이 박자가 게임의 메트로놈입니다.
두드릴 때 움직이고 들을 때 멈추면 됩니다.

한 번 난 소리는 "무슨 소리지" 정도로 끝납니다. 같은 자리에서 두 번 나면
"누가 있다"가 되고, 그때부터 뜁니다.

![복도에서 문을 두드리려고 든 오른손과 수렴하는 조준 표시](Docs/Media/readme/m0-knock-contact.webp)

<sub>내가 두드릴 수도 있고, 대답이 올 수도 있습니다</sub>

냉장고나 배전반이 도는 자리에서는 작은 소리가 묻힙니다. 반대로 상대가
가까워지면 심장이 뛰기 시작하는데 그것도 소리라서, `왼쪽 Ctrl`로 숨을
참아야 합니다.

### 소리에는 크기가 있습니다

문을 길게 눌러 천천히 열면 조용하고, 짧게 탭하면 빠른 대신 건물이 듣습니다.
숫자나 게이지 대신 방금 낸 소리가 어디까지 퍼졌는지를 파문으로 보여 줍니다.

![소음 파문 링이 표시된 4층 복도](Docs/Media/readme/hud-noise-ripple.webp)

<sub>파문 반지름이 그대로 들리는 거리입니다. 벽 하나를 넘으면 줄고 층을 넘으면 더 줄어듭니다.</sub>

바닥도 영향을 줍니다. 장판과 옥상 방수층은 조용하고 철제 계단은 길게 웁니다.
5층 석고 파편이나 밤 4의 고인 물은 걷기만 해도 크게 납니다. 같은 속도로
움직여도 어디를 밟느냐에 따라 들리는 거리가 달라집니다.

### 답은 종이에 있습니다

정답을 짚어 주는 UI가 없습니다. 네 세대짜리 건물에 계량기는 다섯 개고,
검침 기록지에는 한 칸이 비어 있습니다. 민원 대장 정서본 아래 먹지에는
고치기 전 원문이 눌려 있습니다.

![다섯 번째 계량기가 있는 로비 계량기함](Docs/Media/readme/p1-meter-cabinet.webp)

<sub>네 세대인데 계량기는 다섯 개입니다</sub>

서로 다른 두 기록이 같은 것을 가리킬 때 비로소 진실이 됩니다. 조사에도 값이
붙습니다. 먹지를 문지르는 소리도, 두꺼비집을 올리는 소리도 그대로 들립니다.

### 잡혀도 진행은 남습니다

포획은 게임 오버가 아닙니다. 붙잡히면 같은 밤 04시 30분의 침대로 돌아옵니다.
읽은 기록과 알아낸 것은 그대로 남고, 남은 시간만 줄어듭니다.

![위층 사람의 두 팔이 화면 양옆에서 들어와 붙잡는 포획 연출](Docs/Media/readme/m1-capture-embrace.gif)

<sub>얼굴은 나오지 않습니다. 석고 묻은 두 팔과 가까운 노크 두 번뿐입니다.</sub>

거듭 잡혀도 난이도를 낮추라는 팝업은 뜨지 않습니다. 대신 건물이 조용히
힌트를 놓고 갑니다. 배관이 울거나, 문 아래로 종이가 밀려 들어오거나, 그가
필요한 벽에 먼저 귀를 댑니다.

## 조작

| 입력 | 동작 | 입력 | 동작 |
|---|---|---|---|
| `W A S D` | 이동 | 마우스 | 시점 |
| `왼쪽 Shift` | 달리기 | `C` | 앉기 |
| `Space` | 낮게 뛰기 |  |  |
| `E` | 조사 · 상호작용 | `E` 길게 | 조용히 열기 · 벽에 귀 대기 |
| `Q` | 문 두드리기 | `왼쪽 Ctrl` | 숨 참기 |
| `F` | 손전등 | `H` | 단계별 힌트 |
| `Tab` | 지금 들리는 것들 | `F9` | 최근 자동 저장 복원 |
| `F10` | 접근성 설정 | `Esc` | 일시정지 · 뒤로 |

문과 서랍은 길게 눌러 천천히 열면 조용하고 짧게 누르면 빠릅니다. 어느 쪽을
고를지는 그가 지금 어디 있느냐에 달렸습니다. 뛰어내려 세게 착지하면 그것도
소음입니다.

게임패드는 Xbox 배열 기준으로 `A` 조사, `B` 노크, `L3` 달리기, `R3` 앉기,
`LB` 낮게 뛰기, `RT` 엿듣기, `LT` 숨 참기입니다.

## 난이도

시작할 때 고르고 도중에 바꿀 수 있습니다. 어느 쪽을 골라도 이야기와 퍼즐,
도달할 수 있는 결말은 같습니다.

| 모드 | 이런 경우에 |
|---|---|
| 조용한 밤 | 공포는 보고 싶은데 쫓기는 압박이 부담스러울 때. 듣는 범위와 달리는 속도가 줄고, 응답을 기다려 주는 시간이 늘어납니다 |
| 기본 | 설계 기준 |
| 성급한 밤 | 한 번 끝내고 다시 올 때. 처음부터 공격적이고, 자주 다니는 길을 더 빨리 외웁니다 |
| 듣기만 하는 밤 | 추격 자체가 힘들 때. 소리가 난 자리까지 오기는 하지만 붙잡지는 않습니다 |

## 직접 해 보기

배포판은 아직 없습니다. 소스를 받아 직접 빌드해야 합니다.

| 필요한 것 | |
|---|---|
| OS | Windows 10 / 11 (64비트) |
| 엔진 | Unreal Engine 5.8 |
| 빌드 도구 | Visual Studio 2026 — `Game development with C++` 워크로드 |
| 저장소 | Git + Git LFS (에셋이 LFS에 있습니다) |

```powershell
git clone https://github.com/easygap/Indie-Game.git
cd Indie-Game
git lfs pull
.\Scripts\RunGame-MissingFloor.bat
```

`RunGame-MissingFloor.bat`은 입주 첫날 저녁부터 시작합니다. 계약서와 반송 소포를
확인하고 이웃·편의점·옥상 문을 둘러본 뒤 잠들면, 새벽 4시 30분의 첫 밤과
계량기·먹지 퍼즐, 낮과 밤의 순환으로 이어집니다. 에디터로 열려면
`Scripts\RunEditor.bat`을 쓰세요.

첫 실행에서는 본편에 들어가기 전에 소리와 밝기를 한 번 맞춥니다. 2분이면
끝나고, 보정값이 진행이나 결말 조건에 영향을 주지는 않습니다.

노크와 배관음은 분위기용 배경음이 아니라 위·아래·뒤를 구분하는 길 찾기
정보입니다. 헤드폰 기준으로 맞춰 뒀습니다. 스피커도 막지는 않습니다.

## 플레이 전에 알아 두실 것

- 포획 후 암전, 갑작스러운 접근, 화면 흔들림과 점멸이 있습니다. 흔들림과 점멸은
  접근성 설정에서 줄일 수 있습니다.
- 장기간 은폐된 유해를 연상시키는 시각 요소가 나옵니다. 직접적인 신체 훼손
  묘사는 없습니다.
- 층간소음, 무단증축, 산업재해 은폐 같은 현실 소재를 다룹니다. 실제 사건이나
  인물과는 무관합니다.
- 소리가 게임의 절반입니다. 무음으로는 사실상 플레이가 어렵습니다.
- 조명과 사운드 믹스, 애니메이션은 아직 다듬는 중입니다.

## 자주 받는 질문

**공략 없이 풀 수 있나요?**
그렇게 만들었습니다. 막히면 `H`로 단계별 힌트를 볼 수 있는데, 답을 알려 주지
않고 어디를 봐야 하는지만 알려 줍니다.

**세이브는 어떻게 되나요?**
밤 시작과 주요 분기에서 자동 저장됩니다. `F9`로 가장 최근 자동 저장으로
돌아갈 수 있습니다.

**마이크를 정말 쓰나요?**
쓸 수 있지만 기본값은 꺼져 있습니다. 켜면 실제 방의 소음이 게임 안 소음에
더해집니다. 음성이나 파형은 저장도 전송도 하지 않습니다.

**한국어 말고 다른 언어는요?**
지금은 한국어뿐입니다. 음성은 없고 전부 자막입니다.
