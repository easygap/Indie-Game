# 없는 층

> 이 빌라는 4층까지다. 등기부에도, 관리대장에도, 구청 기록에도.
> 그런데 매일 새벽 네시 반, 꼭대기층 천장에서 노크 소리가 난다.

![위층 사람에게 붙잡힌 순간의 실제 게임 화면](Docs/Media/m1-capture-embrace.png)

**없는 층**은 소리로 사냥하는 존재와 한 건물에 갇혀, 서류에 존재하지
않는 층의 진실을 밤마다 조사하는 1인칭 한국 생활공포 게임입니다.
당신이 내는 모든 소리 — 발소리, 문소리, 심지어 겁에 질린 심장 소리 —
가 그것을 부릅니다.

| 장르 | 플레이 | 배경 | 현재 버전 |
|:---:|:---:|:---:|:---:|
| 1인칭 생활공포 · 은신 | 조사 · 추론 · 회피 | 한국의 오래된 빌라 | Windows 개발 프리뷰 |

게임 전체는 이사 온 **저녁의 입주**에서 시작합니다. 잠든 뒤 각 밤은
04:30의 기상으로 열리고, 위층 사람에게 붙잡히면 새 게임이나 그날 처음이
아니라 **같은 밤의 04:30 침대**로만 돌아갑니다. 이미 확인한 기록과 퍼즐의
지식은 사라지지 않지만, 그 존재는 조금 더 조급해집니다.

첫 실행에서는 헤드폰 플레이를 한 번 권합니다. 노크와 배관음은 단순한 배경음이
아니라 위·아래·뒤를 구분하는 길 찾기 정보이며, 실제 시각 04:30~05:30에 타이틀을
켜 두면 멀리서 난 노크가 한 사이클 뒤 대답을 받습니다. 스피커 플레이도 막지
않고, 본편 진행이나 엔딩 조건에는 영향을 주지 않습니다.

> 이 문서의 화면은 모두 실제 플레이 빌드에서 캡처했습니다. 공간·모델·
> 조명은 개발 중이며, 최종 품질을 대표하지 않습니다.

## 그는 보지 못한다. 듣는다

![소리를 따라 다가와 붙잡는 위층 사람과 네시 반의 침대로 되돌아가는 실제 플레이](Docs/Media/night-listener-chase.gif)

<sub>소리를 두 번 들려주면 달려듭니다. 잡혀도 밤의 진행을 잃지 않고, 같은 밤 새벽 네시 반의 침대로 돌아옵니다.</sub>

![위층 사람의 두 팔이 화면 양옆에서 들어와 붙잡는 포획 연출 실제 게임 화면](Docs/Media/m1-capture-embrace.gif)

<sub>포획은 게임 오버가 아닙니다. 얼굴 대신 석고 묻은 두 팔과 가까운 노크 두 번만 남고, 반복할수록 기상 연출은 짧아져 바로 다음 시도로 이어집니다.</sub>

![암전 뒤 403호 침대에서 포옹의 잔상이 풀리는 실제 게임 화면](Docs/Media/m1-capture-wake-echo.gif)

<sub>암전 뒤에는 포옹의 마지막 자세가 3→2→1 순서로 짧게 풀립니다. 잔상이 먼저 사라져도 시야가 돌아오기 전에는 HUD와 조작이 나타나지 않습니다.</sub>

포획은 게임 오버가 아닙니다. 이미 얻은 기록과 퍼즐 지식은 유지되지만, 그 존재는
조금 더 조급해집니다. 반복 시도의 기상 연출은 점점 짧아져 바로 다음 선택으로
돌아갈 수 있습니다.

![다섯 번째 포획 뒤 401호 문 아래에서 메모가 밀려 나오는 실제 플레이](Docs/Media/m65-mercy-note-slide.gif)

<sub>다섯 번 잡히면 난이도 팝업 대신 401호 문 아래에서 짧은 조언이 나옵니다. 상호작용 표시도 자막도 없어, 바닥을 직접 보는 플레이어만 발견합니다.</sub>

위층 사람은 눈이 없습니다. 노크 세 번, 그리고 귀를 기울이는 몇 초.
그 박자가 이 게임의 메트로놈입니다. **그가 두드리는 동안 움직이고,
그가 들을 때 멈추세요.** 냉장고나 배전반의 기계 소리 곁에서는 작은
소리가 묻힙니다. 공포에 심장이 뛰기 시작하면 — 그 소리도 그에게
들립니다.

소리에는 크기가 있습니다. 문을 홀드로 천천히 열면 조용하고, 탭으로
당기면 건물이 듣습니다. 화면 가장자리의 파문 링이 방금 낸 소리가
얼마나 멀리 퍼졌는지 보여 줍니다 — 숫자도, 게이지도 없습니다.

발밑도 규칙의 일부입니다. 장판과 옥상 방수층은 비교적 조용하지만 철제 계단은
길게 울리고, 5층의 석고 파편과 밤 4의 고인 물은 걷기만 해도 크게 들립니다.
같은 이동 속도라도 어느 바닥을 고르느냐에 따라 위층 사람이 듣는 거리가 달라집니다.

<sub>떨어진 소화기 소리는 복도 전체에 퍼집니다. 그리고 그것이 소리를 확인하러 옵니다.</sub>

- 카메라 흔들림·이동 연출 감소 (소음 파문 링은 유지된 채 확장만 멈춤)
- 게임패드 진동 켜기/끄기 (포획 진동은 1.2초 동안 자연스럽게 감쇠)

- 선택형 마이크 소음 입력 (기본값 `끔`, 음성·파형 저장 및 전송 없음)

- 720p·1080p·1440p, 창 모드, VSync와 프레임 제한 설정

## 조작

| 입력 | 동작 | 입력 | 동작 |
|---|---|---|---|
| `W A S D` | 이동 | 마우스 | 시점 |
| `왼쪽 Shift` | 달리기 | `C` | 앉기 |
| `E` | 조사·상호작용 | `E` 길게 | 조용히 열기·벽에 귀 대기 |
| `Q` | 문 두드리기 | `왼쪽 Ctrl` | 숨 참기 |
| `F` | 손전등 | `H` | 단계별 힌트 |
| `Tab` | 듣는 것들 | `F9` | 최근 자동 저장 복원 |
| `F10` | 접근성 설정 | `Esc` | 일시정지·뒤로 |
| 방향키 | 메뉴 이동 | `Enter` / `Space` | 메뉴 선택 |

문과 서랍은 **길게 눌러 천천히** 열면 조용하고, 짧게 누르면 빠르지만
소리가 납니다. 어느 쪽을 고를지는 그가 어디 있느냐에 달렸습니다.
Xbox 배열 게임패드는 `A` 조사, `B` 노크, `L3` 달리기, `R3` 앉기,
`RT` 엿듣기, `LT` 숨 참기를 사용합니다.

## 직접 플레이하기

현재는 완성 배포판이 아닌 **Windows 개발 프리뷰**입니다. 저장소를 소스에서 실행하려면
Windows 10/11, Unreal Engine 5.8, Visual Studio의 `Game development with C++` 워크로드가
필요합니다.

```powershell
git clone https://github.com/easygap/Indie-Game.git
cd Indie-Game
git lfs pull
.\Scripts\RunGame-MissingFloor.bat
```

`RunGame-MissingFloor.bat`이 없는 층의 밤 무대(위층 사람, 그 시간
봉쇄, 계량기·먹지 퍼즐, 낮/밤 순환)를 실행합니다. 에디터에서 열려면
`Scripts\RunEditor.bat`을 사용하세요.

> 주의: 포획 후 암전, 급작스러운 접근, 흔들림·점멸 연출, 장기 유골을 연상시키는
> 시각 요소가 포함됩니다. 흔들림과 점멸은 접근성 설정에서 줄일 수 있습니다.

> 현재 저장소는 개발 프리뷰입니다. 밤 1~4의 핵심 진행과 결말 연결은 들어가
> 있으며, 최종 조명·사운드 믹스·애니메이션과 다양한 화면비·게임패드 체감은
> 계속 다듬고 있습니다.
