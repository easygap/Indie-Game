# 없는 층

낡은 빌라에서 사라진 오빠의 흔적을 찾는 1인칭 공포 게임입니다.
이웃과 이야기를 나누고, 방과 복도를 둘러보며 단서를 모읍니다.
밤에는 소리에 반응하는 적이 돌아다녀서 문 하나도 조심해서 열어야 합니다.

Windows PC · 싱글플레이 · 게임 언어: 한국어 · 개발 중

[Windows 버전 받기](https://github.com/easygap/Indie-Game/releases/download/v1.0.0-test.20260922/MissingFloor-Windows-20260922.zip) · [조작법](#조작)

## 게임 소개

주인공 유담은 연락이 끊긴 오빠를 찾으려고 달빛빌라 403호로 이사합니다.
되돌아온 택배에 적힌 오빠의 주소는 501호인데, 이 건물은 4층까지밖에 없습니다.

이사 온 날, 새벽 네 시 반에 천장에서 노크 소리가 들리기 시작합니다.

![이삿짐과 생활용품이 놓인 유담의 방, 달빛빌라 403호](Docs/Media/readme/game-bedroom.webp)

## 다운로드

지금 받을 수 있는 건 **2026년 9월 22일 테스트 버전**입니다.

1. [Windows용 ZIP 파일(727MB)](https://github.com/easygap/Indie-Game/releases/download/v1.0.0-test.20260922/MissingFloor-Windows-20260922.zip)을 받으세요.
2. 압축을 모두 풀고 `IndieGame.exe`를 실행하세요.
3. **게임 시작**을 누르면 됩니다. 저장된 게임이 있다면 **이어하기**로 계속할 수 있습니다.

진행 상황은 자동으로 저장됩니다.
실행 파일 옆의 `Engine`, `IndieGame` 폴더는 그대로 두세요.

실행이 안 되거나 PC 사양이 궁금하다면 [실행 안내](Docs/PLAYING.md)를 확인해 주세요.

## 조작

`WASD`와 마우스로 움직이고, `E`로 물건을 살펴보거나 문을 엽니다.
문 앞에서 `E`를 길게 누르면 조용히 열 수 있습니다.

게임패드도 지원합니다. 키와 버튼은 설정에서 바꿀 수 있고,
조작법은 `F1` 또는 게임패드 십자키 위쪽으로 다시 볼 수 있습니다.

<details>
<summary>전체 조작법</summary>

| 키 | 동작 |
|---|---|
| `W A S D` · 마우스 | 이동 · 둘러보기 |
| `왼쪽 Shift` · `C` · `Space` | 달리기 · 앉기 · 점프 |
| `E` | 물건 살펴보기 · 문 열기 |
| `E` 길게 | 문을 조용히 열기 · 벽에 귀 대기 |
| `Q` · `왼쪽 Ctrl` | 두드리기 · 숨 참기 |
| `F` | 손전등 |
| `F1` | 목표와 조작법 |
| `Tab` · `H` | 기록 보기(낮) · 힌트 |
| `← →` · 마우스 휠 | 문서 페이지 넘기기 |
| `Esc` · `F10` | 일시정지 · 접근성 설정 |

</details>

## 난이도와 설정

추격이 부담스러울 때는 `F10`에서 **추격 없음**을 고르세요.
적에게 붙잡히지 않고 퍼즐과 이야기를 진행할 수 있습니다.
쉬움·보통·어려움도 게임 중에 바꿀 수 있습니다.

자막이 작으면 글자 크기와 배경 진하기를 조절해 보세요. 소리가 나는 방향을 화면에 표시하거나,
노크를 게임패드 진동으로 알리도록 설정할 수도 있습니다. 화면 흔들림과 깜빡임 줄이기,
길게 누르기 대신 한 번씩 누르기, 배경 음악과 환경음 크기 조절도 지원합니다.

![자막 크기와 배경 진하기, 표시 시간을 조절하는 설정 화면](Docs/Media/readme/settings-accessibility-20260922.webp)

어두운 장면과 갑자기 튀어나오는 적, 큰 소리가 나옵니다. 시작할 때 소리 크기와 밝기를 편하게 맞춰 주세요.
