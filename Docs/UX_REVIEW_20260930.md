# 설정 화면과 배포본 점검 — 2026년 9월 30일

플레이 테스트 0.2.1에서 설정의 모든 항목을 실제 글꼴로 그려 확인했다. 1280×720,
자막 200%에서 영어·일본어·중국어 두 표기의 자막 미리 보기가 설명 영역을 벗어났다.
자막 크기는 유지하고 옵션 간격, 설명 영역의 높이, 미리 보기 폭을 조정했다.
설명이 끝나는 위치도 실제 글자 높이로 계산해 미리 보기가 그 아래에 오도록 했다.

소리·밝기 화면에는 긴 설명이 두 줄로 들어갈 공간을 뒀다. 옵션과 아래 조작 안내는
각자의 폭 안에 맞춘다. 그리는 위치와 마우스로 고르는 위치는 같은 레이아웃을 쓴다.

![720p 영어판 자막 200%](Media/readme/settings-caption-200-20260930-en.webp)

![720p 영어판 소리·밝기 설명](Media/readme/settings-audio-20260930-en.webp)

설정창이 화면을 덮는 동안에는 3D 장면을 그리지 않는다. UI, 밝기 미리 보기와 입력은
계속 작동하며, 메뉴를 닫으면 이전 렌더링 상태로 돌아간다. 새 검사는 이 전환도 확인한다.

조작 안내는 기존의 첫 조작·시간 경과 후 사라지는 흐름을 유지한다. 목표는 잠깐 보여
주고, 필요하면 F1로 다시 확인한다. 현재 코드와 번역에 옛 새벽 4시 44분 설정은 없고,
예전 세이브와 문서의 변경 기록에만 옛 이야기 이름이 남아 있다. Blender 백업도 다시
확인했다. 이번에는 새 텍스처나 3D 소품을 추가하지 않았다.

## 검수 범위

설정 검사는 화면 설정 11개, 접근성 26개를 자막 100%·200%로 각각 확인한다.
소리·밝기 7개는 헤드폰·스피커 양쪽, 키 설정은 입력 대기 상태도 확인한다.
해상도와 언어 한 조합마다 키보드·패드 158장면을 검사하고, 키보드 화면 79장을 남긴다.
설정창의 첫 항목만 확인하던 검사에 이 순회를 추가했으며, 실제 글자 겹침과 화면·패널
밖으로 나간 글자를 Shipping에서도 별도 영수증에 기록한다.

다섯 언어의 에디터 게임 실행에서 720p 설정 순회가 모두 통과했다. 영어판은 번역
수집과 동시에 실행했을 때 첫 프레임 전에 검사 제한 시간이 지나 한 번 실패했고,
수집이 끝난 뒤 단독으로 다시 실행해 158장면 모두 통과했다. 전체 정적 검사와 번역
수집·컴파일도 통과했다. 이때 확인한 외국어 번역은 각 972개 키였다.
이후 낮 목표와 취침 안내를 더해 977개가 됐다. 타이틀의 불필요한 문구 네 개를
제거한 현재 번역은 언어마다 973개 키다.

타이틀을 다시 수집하면서 낮 목표와 취침 안내 다섯 개의 번역이 빈 문자열로
돌아가는 문제를 발견했다. 수집 후 JSON 번역을 다시 적용한 뒤 컴파일하도록
절차를 고쳤다. 네 외국어의 현재 973개 항목은 번역 누락과 형식 오류가 0건이다.
번역 검사도 빠진 키가 있으면 실패하도록 바로잡았다.

배포 후보의 검사 결과와 파일 무결성은 `Saved/Validation/`에 남긴다. Shipping의
검사 결과는 아래에 정리했다. 여러 PC의 성능 인증과 사람이 직접 끝까지 플레이하는 검수는
[성능 기준](PERFORMANCE.md)과 [출시 기준](MISSING_FLOOR_ACCEPTANCE.md)에 따라 따로 확인해야 한다.

## Windows 0.2.3 타이틀 수정 전 배포 후보 확인

Shipping 패키지는 커밋 `98987a399692829c2c49de8c4103fba30d6bb99e`에서
커밋하지 않은 변경 없이 만들었다. 실행 파일의 SHA-256은
`f08af7d18deaf3f11cd34154d7660c486b11c83fa958eadee1ae3e7cfbd15cd0`이다.
아래 검사는 모두 이 파일을 사용했다. 이후 타이틀 화면을 수정했으므로,
새 패키지의 검증 결과와 구분한다.

다섯 언어를 네 해상도에서 검사했다. 설정 3,160장면에서 글자 겹침과 화면·패널
이탈은 0건이었고, 키보드·패드 입력 220건을 통과했다. 자막 100%·200%, 대사와
소리 자막의 분리, 메뉴의 3D 렌더링 중단과 복원도 확인했다. 품질 표시와 실제
적용값이 맞는지, VSync만 바꿔도 품질 단계가 유지되는지 검사에 추가했다.
예전 화면 비율 71%·87%를 100%로 보정하는 두 사례에서는 기존 품질 11항목,
VSync·프레임 제한과 엔딩·에필로그 프로필 키가 유지됐다.

새 입주 저장과 0.2.2의 입주 완료 저장을 각각 16개 복구 사례에 사용했다.
손상 데이터, 없는 맵, 거대한 문자열·배열 길이, 다른 클래스와 8MiB 초과 파일을
거부하고 정상 슬롯이 남아 있으면 복원했다. 원본 저장 해시는 바뀌지 않았다.
Shipping NullRHI 저장 진단의 최대 작업 집합은 새 저장 340.98MiB,
구버전 저장 333.38MiB였다. 일반 플레이의 메모리 측정과는 구분한다.

전체 진행과 엔딩 5프로세스 검사도 통과했다. 실제 선택 직전 저장을 다시 불러와
A/B 결말, A 87초·B 71초 에필로그와 재실행 후 프로필·다섯째 밤 해금을 확인했다.
프로필 파일 경로 불일치는 0건이며, 옛 경로를 허용하는 예외는 사용하지 않았다.
이 자동 검사는 영상·음질·실제 키 홀드와 사람의 완주 평가를 대신하지 않는다.

## Windows 0.2.2 배포본 확인

빌드 소스는 `3057f462e436e88795bbc3b86a6b10b2603b490a`이며 커밋하지 않은 변경 없이
Shipping 패키지를 만들었다. 한국어·영어·일본어·중국어 간체·번체를 1280×720,
1600×900, 1920×1080, 2560×1440에서 검사했다. 설정 3,160장면에서 글자 겹침과
화면·패널 이탈은 0건이었다. 키보드·패드 입력 220건, 대사 100%·200%, 화자와
이어짐 표시, 소리 자막의 분리, 메뉴 렌더링의 중단과 복원도 통과했다.

새 게임의 입주 진행과 자동 저장, 이어하기, 전체 진행 자동 검사와 실제 믹서 녹음을
통과했다. 녹음은 48kHz 스테레오 8.619초였고 최대 -2.431dBFS, 잘린 샘플 0개였다.
0.2.1 배포본이 만든 입주 자동 저장을 0.2.2 배포본에서 복원하는 검사도 통과했다.
사용자의 실제 세이브는 검사에 쓰지 않았다.

게임 파일은 89개, 총 795,580,816바이트다. 실행 파일의 버전·제작자·아이콘과
전체 파일의 SHA-256을 확인했으며 검사 중 배포 폴더는 바뀌지 않았다.
배포 ZIP에는 게임 파일과 한국어·다국어 실행 안내를 넣었다. 압축을 다시 읽어
목록과 모든 파일의 바이트를 원본과 대조했다. ZIP은 635,152,799바이트이며
SHA-256은 `15559a0372321314a1ed700730bd9e5f93f1b2935e62c9ec7daad3c729ee06de`다.
위 두 캡처도 에디터 화면에서 최종 Shipping 화면으로 교체했다.

요약은 [배포본 검수 결과](Validation/Windows-20260930-0.2.2.json)에 있다.
이 결과는 플레이 테스트 배포의 자동 검수이며, 여러 PC의 High 60fps 인증과
사람의 완주 검수를 포함한 정식 출시 승인을 뜻하지 않는다.

## 성능 진단

같은 PC의 에디터 게임 실행에서 D3D12, 1920×1080 High, 내부 해상도 100%로
야간 경로 2,400프레임을 기록했다. 앞의 500프레임을 제외한 진단값이다.

| 항목 | 중앙값 | p95 |
|---|---:|---:|
| 프레임 시간 | 16.463ms | 20.128ms |
| GPU 시간 | 15.811ms | 19.292ms |
| 게임 스레드 | 2.151ms | 2.817ms |
| 드로우콜 | 504 | 707 |
| GPU 메모리 | 3,160MiB | 3,161MiB |

1% low는 46.051fps였고 이 표본에 50ms를 넘는 프레임은 없었다. GPU 비용이
주로 남아 있으며, High 60fps의 출시 합격선에는 못 미친다. 에디터의 짧은 야간 경로를
Shipping 완주나 여러 PC의 성능 인증으로 표시하지 않는다. 원본과 계산 결과는
`Saved/Validation/UXPerfBaselineUser/Saved/Profiling/CSV/`와
`Saved/Validation/UXPerfBaseline/`에 있다.

설정 순회에서도 별도로 2,400프레임을 기록했다. 앞의 500프레임을 뺀 GPU 시간
중앙값은 0.182ms, 드로우콜 중앙값은 9였다. 메뉴 닫기와 게임 화면 복귀도 섞여
있어서 GPU p95는 9.525ms였다. PNG 저장 때문에 프레임 최대값은 135.375ms,
50ms 초과는 4건으로 나왔다. 이 기록은 메뉴에서 3D 렌더링을 쉬는지 진단한 자료이며
플레이 중의 성능 비교나 출시 성능 인증에는 쓰지 않는다. 원본과 계산 결과는
`Saved/Validation/SettingsSweepEnglishFinal-en-720/`와 `Saved/Validation/UXMenuProfile/`에 있다.
