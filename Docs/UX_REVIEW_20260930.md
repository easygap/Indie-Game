# 설정 화면과 배포본 점검 — 2026년 9월 30일

플레이 테스트 0.2.1에서 설정의 모든 항목을 실제 글꼴로 그려 확인했다. 1280×720,
자막 200%에서 영어·일본어·중국어 두 표기의 자막 미리 보기가 설명 영역을 벗어났다.
자막 크기는 유지하고 옵션 간격, 설명 영역의 높이, 미리 보기 폭을 조정했다.
설명이 끝나는 위치도 실제 글자 높이로 계산해 미리 보기가 그 아래에 오도록 했다.

소리·밝기 화면에는 긴 설명이 두 줄로 들어갈 공간을 뒀다. 옵션과 아래 조작 안내는
각자의 폭 안에 맞춘다. 그리는 위치와 마우스로 고르는 위치는 같은 레이아웃을 쓴다.

![720p 영어판 자막 200%](Media/readme/settings-caption-200-20260930-en.webp)

![720p 영어판 소리·밝기 설명](Media/readme/settings-audio-20260930-en.webp)

설정창이 화면을 덮는 동안에는 3D 장면을 그리지 않는다. UI, 밝기 미리 보기와 입력은
계속 작동하며, 메뉴를 닫으면 이전 렌더링 상태로 돌아간다. 새 검사는 이 전환도 확인한다.

조작 안내는 기존의 첫 조작·시간 경과 후 사라지는 흐름을 유지한다. 목표는 잠깐 보여
주고, 필요하면 F1로 다시 확인한다. 현재 코드와 번역에 옛 새벽 4시 44분 설정은 없고,
예전 세이브와 문서의 변경 기록에만 옛 이야기 이름이 남아 있다. Blender 백업도 다시
확인했다. 이번에는 새 텍스처나 3D 소품을 추가하지 않았다.

## 검수 범위

설정 검사는 화면 설정 11개, 접근성 26개를 자막 100%·200%로 각각 확인한다.
소리·밝기 7개는 헤드폰·스피커 양쪽, 키 설정은 입력 대기 상태도 확인한다.
해상도와 언어 한 조합마다 키보드·패드 158장면을 검사하고, 키보드 화면 79장을 남긴다.
설정창의 첫 항목만 확인하던 검사에 이 순회를 추가했으며, 실제 글자 겹침과 화면·패널
밖으로 나간 글자를 Shipping에서도 별도 영수증에 기록한다.

다섯 언어의 에디터 게임 실행에서 720p 설정 순회가 모두 통과했다. 영어판은 번역
수집과 동시에 실행했을 때 첫 프레임 전에 검사 제한 시간이 지나 한 번 실패했고,
수집이 끝난 뒤 단독으로 다시 실행해 158장면 모두 통과했다. 전체 정적 검사와 번역
수집·컴파일도 통과했다. 외국어 번역은 각 972개 키를 유지한다.

배포 후보의 검사 결과와 파일 무결성은 `Saved/Validation/`에 남긴다. Shipping의
최종 확인 결과는 이 문서에 덧붙인다. 여러 PC의 성능 인증과 사람이 직접 끝까지 플레이하는 검수는
[성능 기준](PERFORMANCE.md)과 [출시 기준](MISSING_FLOOR_ACCEPTANCE.md)에 따라 따로 확인해야 한다.

## 성능 진단

같은 PC의 에디터 게임 실행에서 D3D12, 1920×1080 High, 내부 해상도 100%로
야간 경로 2,400프레임을 기록했다. 앞의 500프레임을 제외한 진단값이다.

| 항목 | 중앙값 | p95 |
|---|---:|---:|
| 프레임 시간 | 16.463ms | 20.128ms |
| GPU 시간 | 15.811ms | 19.292ms |
| 게임 스레드 | 2.151ms | 2.817ms |
| 드로우콜 | 504 | 707 |
| GPU 메모리 | 3,160MiB | 3,161MiB |

1% low는 46.051fps였고 이 표본에 50ms를 넘는 프레임은 없었다. GPU 비용이
주로 남아 있으며, High 60fps의 출시 합격선에는 못 미친다. 에디터의 짧은 야간 경로를
Shipping 완주나 여러 PC의 성능 인증으로 표시하지 않는다. 원본과 계산 결과는
`Saved/Validation/UXPerfBaselineUser/Saved/Profiling/CSV/`와
`Saved/Validation/UXPerfBaseline/`에 있다.

설정 순회에서도 별도로 2,400프레임을 기록했다. 앞의 500프레임을 뺀 GPU 시간
중앙값은 0.182ms, 드로우콜 중앙값은 9였다. 메뉴 닫기와 게임 화면 복귀도 섞여
있어서 GPU p95는 9.525ms였다. PNG 저장 때문에 프레임 최대값은 135.375ms,
50ms 초과는 4건으로 나왔다. 이 기록은 메뉴에서 3D 렌더링을 쉬는지 진단한 자료이며
플레이 중의 성능 비교나 출시 성능 인증에는 쓰지 않는다. 원본과 계산 결과는
`Saved/Validation/SettingsSweepEnglishFinal-en-720/`와 `Saved/Validation/UXMenuProfile/`에 있다.

- [AFTERLIGHT: The Apartment](https://store.steampowered.com/app/4986740/AFTERLIGHT_The_Apartment/)와
  [The Strange Lights](https://store.steampowered.com/app/3823950/The_Strange_Lights/?l=koreana)의
  개발자 소개와 공개 화면을 확인했다. 익숙한 생활 공간과 제한된 빛, 소리가 만드는
  긴장을 기준으로 현재 침실·복도·편의점의 소품과 야간 화면을 검토했다.
- [Negative Atmosphere 개발자 인터뷰](https://www.unrealengine.com/developer-interviews/negative-atmosphere-aims-to-be-the-next-great-interstellar-horror-game)의
  실제 용도가 있는 공간과 화면을 덜 가리는 UI에 대한 판단을 검토했다. 상시 조작 안내를
  늘리지 않고 필요할 때 다시 확인하는 현재 흐름을 유지했다.
- [Microsoft의 게임 내 글자 지침](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/101)에
  따라 글자를 키웠을 때도 설명과 조작이 함께 읽히는지 실제 지원 글꼴로 확인했다.
- [Epic의 UE 5.8 Lumen 성능 안내](https://dev.epicgames.com/documentation/en-us/unreal-engine/lumen-performance-guide-for-unreal-engine)와
  [PSO 사전 준비 안내](https://dev.epicgames.com/documentation/en-us/unreal-engine/pso-precaching-for-unreal-engine)를
  현재 설정과 대조했다. 기존 High와 성능 모드의 조명 품질은 유지하고, 화면을 가린
  동안의 불필요한 렌더링부터 줄였다. 내부 해상도를 낮춘 수치를 네이티브 성능으로 쓰지 않는다.
