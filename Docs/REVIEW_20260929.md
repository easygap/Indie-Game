## 이름과 글

공개 제목은 모든 언어에서 `Missing Floor`다. Unreal 모듈과 기존 저장 경로의 `IndieGame`은 호환성을 위해 유지하고, 배포 실행 파일은 `MissingFloor.exe`로 제공한다.

유담의 독백은 눈앞에서 확인한 사실과 그때의 생각만 말한다. 주민은 퍼즐 설명자가 되지 않도록 일상적인 표현을 쓴다. 메뉴에서는 귀신을 ‘적’이라고 부르지 않는다.

건물 주소는 `무영로 27-3`으로 맞췄다. 운송장의 501호와 실제로는 창고라고 등록된 옥탑 사이의 차이가 단서이며, 도로명까지 다르게 적혀 있을 이유는 없다. 석고보드 두께도 현재 설정인 12.5T로 통일했다.

예고편의 ‘잡히면 다시 네 시 반’은 실제 규칙과 달라 지웠다. 붙잡혀도 진행 시간은 유지된다.

## 제작 파일 정리

폐기된 두 스토리 문서는 삭제했다. 이전 내용은 Git 기록에서 확인할 수 있다. 작동 중인 공용 상호작용의 `State.CH01` 식별자는 기존 저장 파일에도 들어 있으므로 임의로 지우지 않는다. `Rebirth` 이름이 남은 현행 검증 스크립트는 `MissingFloor`로 이름을 바꾸고 호출부를 함께 수정했다.

공개 버전은 `v0.2.0`부터 일반적인 버전 번호를 쓴다. 예전 배포 태그는 기존 다운로드 링크를 위해 보관한다. 날짜와 하루 배포 순서는 새 버전 이름에 넣지 않는다.

## 아침 원경 제작

`Content/SourceArt/AI/ApartmentDawnVista.png`는 내장 imagegen으로 기존 밤 원경의 빛과 시간대만 바꿨다. 원본 건물의 창·지붕·전선 위치를 비교하고, 실제 게임의 창틀 뒤에 같은 좌표로 적용했다. 사용한 전체 프롬프트는 같은 폴더의 `ApartmentDawnVista.json`에 있다. 게임에 직접 들어가는 텍스처는 `T_ApartmentDawnVista_D.uasset`이다.

아침 전환은 태양·달·안개·노출·창밖 사진·멀리 보이는 건물에 함께 적용한다. 낮 저장을 불러올 때도 밤 번호와 봉쇄 상태로 결정하므로 새 저장 필드를 만들지 않는다.
