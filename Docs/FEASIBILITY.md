# REBIRTH 출시 타당성 제작 계약

이 표는 `STORY_BIBLE_REBIRTH.md`의 정사를 출시 기능으로 보존하는 최소
범위다. `Static Proxy`는 회색 상자가 아니라 최종 메시·재질·폴리·카메라로
같은 기능과 가독성을 내는 정식 대체 표현이다. 상세 실행 절차와 증거 형식은
`RELEASE_VALIDATION.md`, 구현 결과와 현재 판정은 `IMPLEMENTATION_STATUS.md`를
따른다. 현재 소스의 변경 불가 dirty 회귀 스냅샷은 UE 5.8.1 세 타깃 빌드,
UAsset 감사, Map Check, Editor A/B 종단, 전체 Build/Cook/Stage/Package/Archive,
패키징 Shipping A/B와 46개 저장→종료→재실행 복원을 한 번의 전체 하네스에서
통과했다. 같은 88파일 아카이브로 키보드·게임패드 입력 44회와 실제 한글 HUD
샘플 36개를 1280×720·1600×900·1920×1080·2560×1440에서 검사했고, 최대
200% 대화창·무손실 `이어짐`·독립 환경음 레인·80% 안전 영역과 실행 후
아카이브 무변조도 통과했다. 근거는
`Saved/Validation/RebirthRelease/20260806T072107035Z_51232/summary.json`이다.
다만 dirty 스냅샷이므로 자동 결과는 `PARTIAL`이며, clean SHA 전체 하네스와
수동 청감·실물 입력·초견·다중 하드웨어·클린 PC 증거가 없어 정식 출시는
**BLOCKED**다.
