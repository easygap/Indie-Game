# REBIRTH 출시 타당성 제작 계약

이 문서는 `STORY_BIBLE_REBIRTH.md`의 정사를 줄여 쓰거나 다시 해석하는
문서가 아니다. 정사를 **출시 빌드에서 어떤 기능으로 보존할지**와 그 기능을
어떤 증거로 승인할지를 정한다. 현재 판정은 `서사 명세 잠금 / 정적 계약
로컬 검사 통과·커밋별 증거 보관 전 / UE 런타임·초견 플레이·
콘텐츠·접근성·패키징 미승인 / 출시 BLOCKED`다.

`Static Proxy`는 회색 상자나 디버그 표시를 그대로 출시한다는 뜻이 아니다.
최종 메시·기본 재질·기본 애니메이션으로 정사 기능과 가독성을 보존하되,
고비용 물리·시네마틱을 쓰지 않는 **출시 가능한 대체 표현**이다. `Keep`을
대체하거나 생략할 수 없으며, 아래 증거가 없으면 구현 완료로 세지 않는다.

`Run-Rebirth-Greybox.bat`의 `REBIRTH_GREYBOX PASS`는 P3·P5 라우터의
대표 런타임 증거일 뿐이다. 아래 스파이크와 R1~R4를 대신하지 않는다.
스크립트는 고정 로그 `Saved/Logs/RebirthGreybox.log`를 실행마다 지우고
다시 쓰므로, 실행 직후 현재 SHA의 증거 폴더로 복사하고 종료 코드와 실행
메타데이터를 함께 남겨야 한다. 과거 캡처나 구버전 로그도 현재 커밋의
합격 증거로 재사용하지 않는다.

실행 순서, 증거 폴더·매니페스트 형식, 초견 체크리스트와 G5·G6 판정은
`RELEASE_VALIDATION.md`를 따른다. 구버전 세이브의 출처·오라클은
`SAVE_COMPATIBILITY.md`, 지원 하드웨어·해상도·프레임·메모리 합격선은
`PERFORMANCE.md`를 따른다. 두 문서의 기준은 실행 결과를 본 뒤 완화하지
않으며 실제 픽스처와 측정 원본이 없으면 각각 미검증이다.

`Run-Rebirth-ReleaseValidation.ps1`은 정적 계약, Development 빌드,
Map Check, A/B 무렌더 자동 런타임과 Shipping UAT를 실행별 폴더와
`summary.json`으로 묶는다. `-StaticOnly`와 하나 이상의 Skip 옵션은
최상위 결과를 `PARTIAL`로 남기며 실행하지 않은 단계를 승인하지 않는다.
Skip 없는 자동 하네스 PASS도 S1~S8·R1~R4 실제 입력, 시청각 가독성,
초견·접근성과 별도 PC 패키지 검증을 대신하지 않는다.
