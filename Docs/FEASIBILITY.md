# REBIRTH 출시 타당성 제작 계약

이 표는 `STORY_BIBLE_REBIRTH.md`의 정사를 출시 기능으로 보존하는 최소
범위다. `Static Proxy`는 회색 상자가 아니라 최종 메시·재질·폴리·카메라로
같은 기능과 가독성을 내는 정식 대체 표현이다. 상세 실행 절차와 증거 형식은
`RELEASE_VALIDATION.md`, 구현 결과와 현재 판정은 `IMPLEMENTATION_STATUS.md`를
따른다. 현재는 UE 5.8.1 무화면 빌드·UAsset 감사·맵 검사·저장 스파이크와
A/B 종단 사전 점검까지 통과했다. 다만 clean SHA 전체 하네스, 화면·청감·
실제 입력·Shipping 증거가 없어 정식 출시는 **BLOCKED**다.
