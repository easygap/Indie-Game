# 창문·주방·펌프 조작반 점검

2026년 9월 16일까지 공개된 자료를 찾아 적용했다. 비교 기준은 `a10832c`다. 이번에는 기존 순회에서 빠졌던 창문, 싱크볼 안쪽, 펌프 조작반을 가까이서 확인했다.

## 화면에서 찾은 문제

창문 잠금장치가 유리 한가운데 떠 있었고, 큰 발광판 한 장이 창짝과 가스켓을 덮고 있었다. 두 레일의 높이와 깊이를 맞추고, 실물 크리센트 사진을 보고 가운데 잠금장치를 다시 만들었다. 유리는 각 창짝 안에 따로 끼운다. 이전에 남겨 뒀던 창문 겹침 검사 예외도 지웠다.

창밖에는 한국 주택가 사진을 참고해 만든 원경을 넣었다. 카메라에서 유리를 통과하는 시선을 10m 뒤의 가상 평면에 투영한다. 옆으로 움직이면 보이는 풍경도 달라지고, 두 창짝이 같은 풍경을 이어서 보여 준다. 접근할 수 없는 원경에만 쓰는 평면 방식이라 건물 사이의 입체 가림까지 계산하지는 않는다. 창틀·레일·잠금장치는 실제 3D다.

싱크대는 상판만 뚫려 있었다. 하부장 윗면이 볼 안을 막아서 배수구가 가려지고 얕은 사각 쟁반처럼 보였다. 하부장에도 볼이 들어갈 공간을 냈다. 인덕션의 큰 흰 띠는 지우고 검은 유리 위에 작은 전원·조절 기호를 넣었다.

## 설비를 읽고 조작하는 퍼즐

펌프 조작반은 나무처럼 보이던 상자와 큰 검은 원을 없앴다. 국내 제품 사진에서 확인한 얕은 판금 함체, 문틈, 경첩, 원형 표시등, 회전 스위치를 Blender로 제작했다. 함체는 1,100삼각형, 손잡이는 196삼각형이며 각각 4단계 LOD를 쓴다. 자주 들여다보는 조작반 인쇄는 2K, 작은 손잡이는 512px로 굽고 밉 스트리밍을 유지한다.

전원등은 대기 중에도 켜져 있다. 순서를 틀리면 고장등이 켜지고 펌프가 정지한다. 배관 소리가 잦아드는 10초 뒤에 고장등이 꺼지며, 다시 조작할 수 있다. 정상 운전 때는 손잡이가 수동 위치로 돌아가고 운전등과 펌프 소리가 함께 켜진다. 밤이 끝나거나 실패하면 운전 표시도 함께 정지한다.

옆의 종이는 정답 세 줄 대신 과거 점검 메모로 바꿨다. 넘친 날과 펌프가 멎은 날의 밸브 상태를 대조하면 배수→우회→펌프 순서를 추론할 수 있다. 순서를 외워 누르는 절차에서 고장 원인을 읽는 문제로 바꾼 것이다. 기존 저장 파일의 밸브 기록과 실패 후 재시도 흐름은 유지한다. 인쇄와 읽기 창에는 같은 단서를 넣었다.

## 성능 측정

RTX 3060 8GB, Ryzen 9 7900X, Windows 11, D3D12에서 같은 순회 경로를 재생했다. UE 5.8 Development 게임 실행이며 출력은 1920×1080이다. 높은 품질은 렌더 해상도 100%, 성능 설정은 71%와 TSR을 쓴다. 각 기록의 첫 120프레임은 제외했다. 빌드·이미지 변환·다른 게임 실행과 겹치지 않게 측정했다.

| 구간·설정 | 이전 중앙값 / p95 | 수정 후 중앙값 / p95 | 수정 후 GPU 중앙값 |
| --- | ---: | ---: | ---: |
| 편의점 · 높은 품질 | 18.51 / 21.55ms | 15.43 / 18.72ms | 14.78ms |
| 편의점 · 성능 | 8.86 / 10.29ms | 7.71 / 9.54ms | 7.09ms |
| 승강장·복도 · 높은 품질 | 15.36 / 18.00ms | 16.13 / 18.51ms | 15.61ms |
| 승강장·복도 · 성능 | 7.87 / 9.79ms | 7.65 / 9.49ms | 7.06ms |

p95는 전체 프레임의 95%가 이 시간 안에 끝났다는 뜻이다. 편의점 높은 품질의 중앙 프레임 시간은 약 17% 줄었다. 진열대를 가까이 보는 구간은 여전히 16.67ms를 넘기므로 높은 품질에서 항상 60fps가 나오는 상태는 아니다. 승강장·복도의 높은 품질은 15.36ms에서 16.13ms로 늘었다. 이번 조명 변경의 개선 효과는 편의점 구간에서 확인했다.

천장등 네 개의 방향과 영향 반경을 바꿨다. 제품 그림자와 기존 품질 설정은 유지했다. 원인 확인을 위해 그림자를 끄거나 VSM 샘플 수를 줄인 실행도 해 봤지만 최종 설정에는 넣지 않았다. 사진 원경은 창밖에만 쓰고, 손이 닿는 소품은 3D 메시와 기존 LOD를 쓴다.

## 게임 반영 확인

- C++ Development Editor 빌드 완료. 창틀·하부장·인덕션과 새 조작반을 다시 가져왔다.
- 실제 게임의 창문·주방·펌프 근접 화면 9장, 편의점·골목·복도·옥상 순회 화면 21장을 다시 촬영했다.
- 펌프 대기→고장→10초 뒤 복구→재가동→밤 종료를 실제 상호작용으로 진행했다. 표시등 재질과 물소리 상태를 함께 검사했다.
- 문·통로·승강장과 샛길의 캡슐 이동 검사 24개 통과. 조작 검사는 30·60·120fps에서 각각 통과했다.
- 밤 진행 검사와 CCTV 화면 판독 통과. 가려진 사물 상호작용, 닫힌 문을 통한 붙잡기, 실패 장면의 몸·얼굴 위치 검사도 통과했다.
- `Scripts/Validate-Project.ps1` 통과. 창문 겹침 예외를 지운 상태에서 배치·조명·겹친 면 검사에 새 오류가 없다. 여러 메시를 합친 외부 원본 6종은 기존 자동 크기 검사 범위에 들어 있지 않다.
