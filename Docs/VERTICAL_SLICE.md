# Prologue Morning Vertical Slice

## 범위

`Prologue_Morning` 한 맵에서 암전 속 알람부터 편의점에서 생수를 계산하는 순간까지를 구현합니다. 강제 기상 연출은 60~90초 이내, 아침 루틴 전체(냉장고 → 지갑 → 골목 → 편의점 → 계산)는 자유 탐색을 포함해 5~10분을 목표로 합니다.

공간은 한 맵 안에서 수직으로 이어집니다. 404호는 4층(z+900)에 있고, 엘리베이터가 1층 로비로 내려보냅니다.

- **404호 (4층, 5평 원룸)**: 침대, 협탁·알람, 책상·지갑, 옷장, 부엌 카운터, 냉장고, 현관
- **4층 공용 복도**: 401·403호 문패, 소화전함, 골목이 보이는 창, 아래로 꺼지는 계단실
- **엘리베이터**: 호출 → 탑승 → 층 차임과 기계 험을 들으며 하강 → 로비 도착
- **1층 로비**: 세대 우편함, 관리비 공지, 프레임형 유리 공동현관
- **새벽 골목**: 가로등 세 개, 전신주, 셔터 내린 상가 4곳, 샛골목(막다른 어둠), 쓰레기(물리)
- **편의점**: 전면 유리와 자동문, 긴 계산대·담배월, 양면 곤돌라 2열, 오픈 쇼케이스, 유리도어 음료 쿨러 6칸

## 상태 흐름

기상 연출은 기존 Wake 상태 머신을 그대로 사용합니다.

```text
FadeIn -> BedLocked -> AwaitAlarm -> GettingUp -> FreeRoam
```

FreeRoam 이후는 Morning 디렉터가 스토리 태그에서 파생되는 단계로 목표를 전환합니다.

```text
CheckFridge -> TakeWallet -> GoToStore -> FindWater -> PayAtCounter -> Complete
```

- `CheckFridge`: 냉장고 문을 열면 내부 조명·빈 선반이 보이고, 잠시 후 "물이 없다"를 인지
- `TakeWallet`: 책상 위 지갑을 챙겨야 현관문이 열림
- `GoToStore`: 세대 현관 → 4층 복도 → 엘리베이터 → 로비 → 공동현관. 골목으로 나서면 앰비언스와 야외 드론 BGM 시작, 중간 가로등 소등 비트
- `FindWater`: 자동문 차임과 함께 입장, 쿨러에서 생수 픽업(손에 들림)
- `PayAtCounter`: 점원이 없는 카운터에서 셀프 계산(바코드·계산기 사운드)
- `Complete`: 구매 완료 자동 저장, 유령 차임 비트, "집으로 돌아가자"

각 단계는 Gameplay Tag(`State.CH01.Morning.*`)로만 판정하며, 체크포인트(`Checkpoint.CH01.*`)는 냉장고 확인·골목 진입·편의점 진입·구매 완료 시점에 비동기 자동 저장됩니다.

## 공포 연출 기준

- 알람이 꺼진 뒤 룸톤과 냉장고 험이 선명해지는 대비를 사용합니다.
- 새벽 창빛(원룸), 가로등 웅덩이(골목), 형광등 백색광(편의점)의 조명 대비가 공간 정체성을 만듭니다.
- 편의점의 쾌활한 징글 BGM은 텅 빈 새벽 매장과의 부조화를 위한 장치입니다.
- 이상 현상은 모두 진행을 막지 않는 1회성 비트입니다.
  - 골목 중간 가로등이 플레이어가 지날 때 명멸하다 꺼짐
  - 생수를 집는 순간 징글이 잠시 끊기고 형광등이 어두워졌다 복귀
  - 계산 직후, 닫힌 자동문에서 차임이 한 번 저절로 울림
- 카메라 강제 회전, 화면 플래시, 큰 충격음과 직접적인 괴물 노출은 사용하지 않습니다.

## 완료 조건

- 키보드·마우스로 알람부터 생수 계산까지 끊김 없이 완료할 수 있습니다.
- 침대 상태에서는 이동하지 않으며 시점 제한이 정상 작동합니다.
- 알람을 연타하거나 길게 눌러도 소리와 이벤트는 한 번만 종료됩니다.
- 냉장고 확인 전에는 현관문이 열리지 않고, 이유가 프롬프트와 속마음으로 안내됩니다.
- 생수를 든 상태에서만 계산대가 상호작용을 허용하며, 구매는 한 번만 발생합니다.
- 각 단계 전환은 프레임률과 무관하게 스토리 태그로만 판정됩니다.
- 저장 후 불러오면 소비된 연출(냉장고 확인, 가로등, 차임)이 반복되지 않습니다.
- 이상 현상은 각각 한 번만 발생하며 보지 못해도 진행할 수 있습니다.
- 핵심 사운드는 목표·속마음 텍스트라는 시각적 대체 단서가 있습니다.
- 전체 실행에서 소프트락, 충돌 끼임과 중복 입력 컨텍스트가 없습니다.
- 런타임 로그가 깨끗합니다.
