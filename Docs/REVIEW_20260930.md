## 0.2.3 화면 수정 검수 — 2026년 10월 1일

타이틀에 게임 속 소리 자막이 남던 문제를 고치고, 메뉴 왼쪽의 선과 눈금,
큰 선택 배경, 상시 조작 안내, 「달빛빌라 403호」 표기를 뺐다. 선택 항목은
글자 크기 22, 나머지는 18을 기준으로 표시하며 크기·굵기·밝기로 초점을 구분한다.
설정 화면의 세로 장식도 뺐다. 소리 자막은 게임 중 유지하고, 일반 타이틀에서는
표시하지 않는다. 일시정지 6초 뒤에는 남은 자막을 다시 읽을 수 있다.

빌드 커밋 `aec8fd3ea7ad89e3bec64e245c62e5c60520061f`의 새 Windows Shipping에서
다섯 언어×네 해상도의 설정 3,160장면·입력 220건을 통과했고 글자 겹침·영역 이탈은
0건이었다. 새 저장과 0.2.2 입주 완료 저장의 복원·손상 거부를 각각 16가지씩,
엔딩·에필로그·프로필 복원을 다섯 실행으로 확인했다. 실제 믹서 녹음의 잘린 샘플은
0개였다. 1080p High 야간 경로는 세 번 모두 로컬 프레임 기준을 통과했다.
아래 Safe 후보와 에디터 진단은 당시 결과로 남기며 새 후보의 측정과 합치지 않는다.

![수정한 Shipping 타이틀](Media/readme/title-menu-first-run-1080.webp)

현재 배포는 플레이 테스트 0.2.3이다. 실제 PC 여섯 대의 성능 측정과 사람의 완주
검수는 수행하지 못했고, 추가 장비와 테스터가 아직 없다는 답을 받았다.
정식 출시 완료로 판정하지 않는다. 최신 결과와 범위는
[배포 전 검수 JSON](Validation/Windows-20261001-0.2.3.json),
[설정 화면과 배포본 점검](UX_REVIEW_20260930.md),
[성능 기준](PERFORMANCE.md)에 남겼다. 아래 기록은 작업 당시의 상태를 보존한다.

## 업로드를 보류했을 때의 기록

당시 사용자 요청으로 GitHub 업로드를 보류했고 새 커밋·푸시·릴리스는 만들지 않았다.
같은 작업 폴더의 병행 정리가 끝나지 않아, 커밋하지 않은 변경 전체를 이 문서의
검증 결과에 포함하지 않았다. 새 다운로드 링크도 공개 전에 바꾸지 않았으며,
그때 README는 플레이 테스트 0.2.0을 가리켰다.

## 합친 뒤 (2026-09-30 오후)

같은 폴더에서 진행한 코드 정리(검수 러너 13개와 호출되지 않는 C++ 약 3,400줄 삭제)와
이 점검의 변경을 합쳐 주제별로 커밋했다. 합본에서 C++ 빌드와 정적 전체 검사를 다시
통과했고, 번역 원본은 바뀐 줄 번호로 다시 모아 locres를 새로 만들었다. 지운 검수
러너는 사용자 결정으로 되살리지 않는다. 같은 공간과 동선은 전체 진행 프로브, README
캡처, 패키지 검사가 확인한다. 아래 「합치기 전 확인한 결과」와 「병행 작업 후 확인할 부분」은
합치기 전의 기록이다.

합친 커밋은 GitHub에 올렸다. 이때는 릴리스를 만들기 전이었다.

## 이번에 고친 부분

- 센서 노이즈, 화면 전체 흐림·과도한 샤프닝, 월드와 추격 효과의 필름 그레인을
  제거했다. 렌즈 재질은 미세한 가장자리 왜곡만 남기고 화면 조회를 12회에서
  3회로 줄였다. FPS 개선 수치는 아직 측정하지 않았다.
- 먼지 흔적이 96개 이후 멈추거나 같은 개수에서 위치·방향이 바뀌지 않던 문제를
  고쳤다. 다른 층의 흔적도 제외하고 0.25초마다 변경 여부를 확인한다.
- 대본 소리가 가득 찼을 때 추가 소모음이 제한을 우회하던 경로를 막았다.
  추격 종료 음악도 재생 뒤 등록하도록 바꿔 짧은 퇴출 페이드가 실제 적용되게 했다.
- 영어·일본어·중국어 두 표기의 계약서에서 빠진 공용 옥상 단서를 복구했다.
  신발장을 가리키던 옛 번역, 노크 인용문, 위층 사람의 호칭과 설정 설명도 맞췄다.
- 전역 Lumen 거칠기 강제를 High 품질의 clamp로 옮겼다. 기존 0.25 한계는 유지한다.
- 패키지 전체 해시·필수 파일·출시 커밋 검사와 변조 회귀 검사를 추가했다.
  커밋 훅은 easygap 이름과 메일을 함께 확인하고 공동저자·도구 트레일러를 막는다.
- 호출되지 않으며 현재 재질을 옛 단색 재질로 덮어쓰는
  `Scripts/create_prototype_materials.py`를 삭제했다.
- 에셋 스타일 지침의 필름 그레인 요구를 없앴다. 8월 3일 생성 프롬프트의 04:44는
  과거 원문임을 명시하고 현재 04:30 설정과 새 생성 지침으로 연결했다.

현재 게임의 Source·Config·Localization에서는 04:44 설정 충돌이 발견되지 않았다.
생성 이력의 실제 프롬프트는 출처를 보존하기 위해 내용을 소급해서 바꾸지 않았다.
이번에는 새 이미지를 생성하거나 새 3D 모델을 추가하지 않았다.

## 합치기 전 확인한 결과

아래 수치와 대기 항목은 오전 점검 당시의 기록이다. 이후의 수정과 배포본 검증은
위쪽 현재 상태와 연결된 점검 문서를 따른다. 이때 외국어별 972개였던 번역은
낮 목표와 취침 안내를 더한 당시에는 각 977개였고, 타이틀의 문구 네 개를 뺀 현재는 973개다.

- 수정한 C++의 UE 5.8 에디터 빌드 두 차례 통과.
- 정적 전체 검사는 병행 정리 전 통과. 이후 `IGIgnoreDirectStart` 제거와 검사 코드
  수정이 들어왔으므로 최종 합본에서 다시 실행해야 한다.
- 10:31 실행한 전체 진행 프로브 통과. 먼지의 실제 인스턴스 위치·회전·다른 층 제외·
  96개 포화 교체·초기화 검사도 통과했다.
- 번역은 외국어별 972개 키의 원본·PO 일치와 형식 인자를 확인하고 locres를 재생성했다.
- 실제 D3D12 화면 8장을 1920×1080으로 새로 촬영하고 README 축소본을 갱신했다.
- 마지막 야간 밝기 검사에서는 11지점 중 7지점 통과, 4지점 실패했다. `beam_dust`,
  `entity_rim`, `cavity_wall`, `residue_corridor`의 암부 비율이 기존 승인 범위를
  벗어났다. 기준을 넓혀 통과시키지 않았다. 병행 정리 완료 뒤 고정된 후보에서
  렌즈 변화와 조명 영향을 나눠 확인해야 한다.
- 최종 Shipping 패키지, 새 배포본의 저장·이어하기·언어별 화면과 성능 측정은 남았다.
  여러 PC에서 확인하지 않은 최소·권장 사양을 출시 인증으로 표시하지 않는다.

로그는 `Saved/Validation/`의 `editor-build-20260930.log`,
`editor-final-20260930.log`, `visual-capture-20260930.log`,
`final-static-20260930.log`, `night-histogram-20260930.log`에 있다.
전체 진행 로그는 `Saved/Logs/FullReview20260930.log`다.

에디터의 한국어 초기화 때 나오는 `Condition failed` 15개는 기존 실행들에서도
반복되는 엔진 자가테스트 실패다. 현지화한 오류 문장을 영어 문자열과 비교하는
엔진 테스트를 확인했다. 게임 오류가 없다는 근거로 이 출력을 무시하지 않으며,
최종 Shipping 후보의 실행 로그는 따로 검사해야 한다.

## 병행 작업 후 확인할 부분

다른 도구가 제거 중인 저널·화면 설정 프리뷰, 침실·차단기·옥상·소품 검사에는
실제 상호작용과 성능 비교에 쓰이던 경로가 포함돼 있다. 삭제를 되돌리지는 않았다.
대체 검증이 있는지 확인한 뒤 최종 전체 검사와 패키징을 진행해야 한다.

## 참고 자료와 적용 판단

아래 자료는 2026년 9월 30일까지 공개된 내용을 기준으로 삼았다. 특히 타이틀의
글자 크기 22·18과 선택 표현은 이 게임에 맞춘 해석이며, 개발사의 원본 규격이 아니다.

  기준으로 빌라의 재질과 문구를 검토했다.

  VHS 질감 자체를 이 게임의 필수 조건으로 삼지는 않았다.
- [Thomas Grip의 공포 제작 경험](https://frictionalgames.com/2019-10-9-years-9-lessons-on-horror/):

  참고했다. 단서와 흔적을 또렷하게 남기고, 타이틀에서는 장식과 상시 안내가
  배경 공간에 쏠릴 주의를 빼앗지 않도록 덜어냈다.

  이미 받은 힌트가 반복되거나 아직 쓸 수 없는 총의 장착 힌트가 뜨던 문제를
  고쳤다는 기록을 확인했다. 타이틀의 소리 자막 누수를 막는 판단에 참고했으며,
  실제 플레이의 소리 자막과 설정의 자막 미리보기는 유지한다.
- [Alien: Isolation UI 책임자 Jon McKellan 인터뷰](https://www.artofthetitle.com/title/alien-isolation/):
  인지·기억을 나타내는 오버레이는 간단하고 쓰기 쉽게, 세계 안의 기계 화면은
  해당 물건의 성격에 맞게 나눴다는 설명을 참고했다. 메뉴는 읽기 쉬운 글자와
  분명한 선택 상태에 집중하고, 분위기는 배경 공간이 맡도록 정리했다.
- [Epic UE 5.8 후처리 안내](https://dev.epicgames.com/documentation/unreal-engine/post-process-effects-in-unreal-engine):

- [Epic Lumen 성능 안내](https://dev.epicgames.com/documentation/unreal-engine/lumen-performance-guide-for-unreal-engine):
  설치된 엔진 소스와 대조해 품질별 거칠기 clamp를 적용했다.
- [GDC 2026 현지화 강연 소개](https://gdcvault.com/play/1035708/Common-Dev-Mistakes-That-Lead):
  대사뿐 아니라 게임 맥락과 UI·동적 텍스트의 일치를 점검하는 참고 자료로 썼다.

최신 기능의 이름을 적용하는 것만으로 성능이나 몰입감이 좋아졌다고 판단하지 않는다.
현재 장면과 플레이 동작에서 확인한 결함을 우선 수정했다.
