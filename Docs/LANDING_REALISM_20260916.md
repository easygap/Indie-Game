# 승강기 앞과 복도 배치 점검

자료는 2026년 9월 15일까지 공개된 내용을 기준으로 찾았고, 반영과 검증은 9월 16일에 마쳤다. 비교 기준은 `85382b8`이다.

## 공간과 소품

1층 로비 안쪽 폭을 140cm에서 230cm로 늘렸다. 우편함과 게시판은 안쪽 벽으로 옮기고 승강기 앞에서 돌아서거나 현관으로 나가는 길을 비웠다. 4층은 승강기 옆으로 비켜 설 수 있게 해당 구간의 폭을 220cm로 늘렸다. 문 개구부는 그대로 두고 대기 공간을 넓혔다.

우편함은 낱개 상자 아홉 개를 겹친 형태에서 얇은 판금 일체형으로 바꿨다. 투입구, 열쇠 구멍, 201~403호 표기를 넣었다. 승강기 버튼은 9×24cm의 얕은 스테인리스 판으로 바꿨다. 문틀을 장면과 승강기가 중복으로 만들던 부분, 닫힌 문틈으로 실내등이 새던 부분도 수정했다. 층 표시는 실제 운행에 따라 4→3→2→1, 복귀 때 1→2→3→4로 바뀐다.

벽에는 덧칠한 도장면을 사용했다. 거친 미장 자국을 크게 반복하던 노멀·음영은 걷어냈다. 넓힌 모서리까지 도장선과 걸레받이를 잇고, 바닥과 외벽이 같은 높이에서 겹쳐 벽돌이 드러나던 접합부를 수정했다.

복도 문 옆에는 실내 모니터 그림이 상자 여러 면에 반복되고 있었다. 실외용 카메라 모델로 교체하고 두 집의 기기를 서로 다른 쪽 벽에 나눴다. 분전반 아래에 떠서 굵은 돌출물처럼 보이던 녹 합성판은 제거했다.

[공동현관에 설치한 카메라](Media/landing-entrance.png) · [4층 승강기 옆 대기 공간](Media/readme/landing-fourth-waiting.webp) · [게시판의 문서 배치](Media/readme/landing-noticeboard.webp)

관리실 펌프도 원통 몇 개로 만든 임시 형태가 남아 있었다. 제품 사진을 기준으로 모터 방열판, 전장함, 케이싱, 흡입·토출구를 갖춘 모델로 교체했다. 끊긴 관을 벽과 천장까지 잇고 벽 지지대를 달았다. 상부 배관은 선택반 옆으로 돌려 스위치를 가리지 않게 했다. 선택반 옆 세척 절차서는 A4 크기의 얇은 종이로 바꾸고, 읽기 창에 나오는 조작 순서와 주의사항을 인쇄했다.

검침 기록지는 계량기 옆 클립보드에, 소음 민원 인쇄본은 게시판에 옮겼다. 우편 투입구나 승강기 버튼 앞을 종이로 가리지 않는다. A4 종이 두께도 1.2cm에서 0.8mm로 줄이고, 읽기 창과 같은 기록을 실제 종이에 인쇄했다. 이번 이야기 수정 범위는 이 두 단서의 맥락과 배치다.

협탁 조명은 집게를 상판 가장자리에 맞추는 코드가 있었지만 이미 고정 소품으로 등록돼 위치 변경이 막혔다. 등록을 풀어 위치를 보정한 뒤 다시 고정 소품으로 등록하도록 수정했다. [실제 화면](Media/bedroom-lamp.png)에서 집게가 상판에 닿는 것을 확인했고 해당 이동 경고도 사라졌다.

## 적용 기준

[Level Design Book의 공간 치수 설명](https://book.leveldesignbook.com/process/blockout/metrics)을 참고해 실물 치수와 플레이 공간을 구분했다. 작은 철물은 실제 비율로 만들고, 통행·대기 공간은 캐릭터의 캡슐과 1인칭 시야로 확인했다. 호출판은 이동 캡슐을 막지 않으며 조준 판정은 유지한다.

[Epic의 가시성·오클루전 안내](https://dev.epicgames.com/documentation/en-us/unreal-engine/visibility-and-occlusion-culling-in-unreal-engine)와 [인스턴싱 안내](https://dev.epicgames.com/documentation/unreal-engine/instanced-static-mesh-component-in-unreal-engine)를 대조했다. 기존 거리별 표시와 반복 소품의 인스턴싱을 유지하면서, 승강기 고정 부품의 불필요한 동적 처리를 줄였다. 편의점 상품 1,318개는 기존의 27개 인스턴스 묶음을 유지한다. 관리실 배관과 지지대는 한 메시로 묶었다. 벽과 천장의 도장 재질 다섯 종은 색상 텍스처 한 장을 공유한다.

다섯 모델 모두 UE 반입 때 4단계 LOD를 만든다. 반입 중 퇴화 삼각형 제거 등으로 원본 수와 UE의 최상위 LOD 수는 일부 다를 수 있다. 작은 철물 때문에 Nanite나 새 렌더링 경로를 추가하지 않았다.

[Silent Hill: Townfall 개발진의 1인칭 설계 설명](https://blog.playstation.com/2026/02/12/silent-hill-townfall-reveals-first-person-gameplay-in-a-new-trailer/)도 함께 읽었다. 이번 적용은 계량기와 기록을 같은 자리에서 대조하게 하고 민원 자료가 놓인 이유를 분명히 하는 데 집중했다. 개별 작품의 방식을 업계 전체의 유행으로 단정하지 않는다.

## 검증

UE 5.8 에디터 개발 빌드를 완료했다. D3D12·1920×1080·High 설정으로 승강장 12개 시점, 편의점·골목·실내·옥상 21개 시점, 공용 설비 8개 시점과 CCTV 원본 4장을 캡처했다. CCTV 대기 화면도 바뀐 복도 사진으로 다시 반입했다. README의 복도·계산대·계량기·관리실 사진은 이 실행의 화면으로 갱신했다.

- 이동 캡슐 검사 21개와 호출판·기록지 조준 검사 3개 통과. 새 대기 공간에서 이동·회전하고 원래 동선으로 돌아갈 수 있다.
- 30·60·120fps에서 이동·계단·문·붙잡힘 검사 통과.
- 승강기 왕복 검사 통과. 같은 승강기를 쓰는 기존 시나리오에서 2층 중간 정차, 1층 도착, 4층 복귀와 층 표시 순서를 확인했다.
- 현재 게임의 시작 경로와 전체 퍼즐 진행 검사 통과. 전원을 끄고 켜는 계량기 실험, 열쇠 습득과 문 해제, 밤 2·3의 귀가 동선도 포함한다.
- CCTV 5번 입력의 실제 GPU 렌더 검사 통과. 352×288 화면을 입력 때 할당하고, 재생을 마치면 해제하며 중복 재생은 거부했다. 실행별 캡처 횟수와 화면 밝기는 검사 기록에 남겼다.
- `Validate-Project.ps1` 통과. 새 메시·재질 참조, 표면 투영, 종이 두께, 동일 평면 겹침, README 링크를 검사했다.

[검사 기록](Performance/Landing20260916-checks.txt)에 실행 결과를 보존했다. 자동 검사의 기존 창문 장식·창틀 겹침 1건은 미결 목록에 남아 있다.
