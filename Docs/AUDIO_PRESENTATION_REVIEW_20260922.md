# 소리와 공포 연출 검수 · 2026-09-22

UE 5.8, Windows에서 실제 오디오 장치를 켜고 연출 전환을 확인했다.
설정값만 비교하던 검사에 실제 믹서의 음량과 출력 녹음을 추가했다.

## 플레이 중 달라진 점

| 상황 | 발견한 문제와 수정 |
|---|---|
| 음악·환경음 설정 | 런타임에 만든 여섯 SoundClass가 실제 장치에 등록되지 않아 볼륨과 더킹이 적용되지 않았다. 월드 시작 때 등록하고 종료 때 해제한다. |
| 적의 접근 | 효과음이 몰리면 계속 들려야 할 끌림 소리까지 밀려 멎었다. 이동음·호흡·현재 음악과 전환 중인 음악을 보호한다. |
| 적이 멀어진 뒤 | 압박음이 거의 사라진 상태에서는 작은 음량 변화로 취급돼 루프 종료를 건너뛰었다. 0으로 내려가는 전환은 반드시 처리한다. |
| 가까이서 마주침 | 방향만 맞으면 벽 너머에서도 놀람이 터졌다. 눈높이에서 적의 얼굴까지 가림을 확인하고, 실제로 소리가 재생됐을 때만 재사용 대기시간을 쓴다. |
| 추격 재개 | 잠깐 놓쳤다가 다시 쫓길 때 비명과 음악이 처음부터 반복됐다. 비명 사이에 6초를 두고, 빠지던 음악이 남아 있으면 같은 박자에서 이어 간다. |
| 추격 음악 반복 | 마지막 타격음이 마디를 약 92ms 늘리고 있었다. 마지막 음을 마디 안에 넣어 118 BPM을 유지한다. |
| 숨 참기·침묵 | 이미 시작된 들숨과 평소 호흡이 남아 연출을 덮었다. 함께 짧게 걷고, 다시 숨 쉴 때는 들숨 아래로 평소 호흡을 낮춘다. |
| 붙잡힘 | 포획을 마지막 장면과 같은 음악 상태로 취급하고 있었다. 별도 상태에서 추격 음악과 거리 압박을 0.12초에 걷어 접촉음이 들리게 한다. |

## 실제 실행 결과

`Run-AudioPresentationProbe.ps1`의 45개 확인 항목을 최대 프레임 설정 30·60·120에서
각각 통과했다. 설정한 프레임을 항상 유지했다는 성능 측정은 아니다.
벽의 가림, 놀람 중복, 발음 상한, 음악 재개, 포획, 숨 참기, 침묵, 타이틀 복귀와
여섯 버스의 실제 음량을 확인했다. 음악 음소거와 전체 음량도 오디오 스레드에서 읽었다.

| 최대 프레임 설정 | 녹음 길이 | 샘플 피크 | RMS | 클리핑 샘플 |
|---|---:|---:|---:|---:|
| 30 | 8.299초 | -5.104 dBFS | -23.248 dBFS | 0 |
| 60 | 8.320초 | -3.016 dBFS | -23.093 dBFS | 0 |
| 120 | 8.320초 | -2.664 dBFS | -23.020 dBFS | 0 |

48kHz·스테레오·16비트 PCM 녹음이다. 여러 효과음을 한꺼번에 울리는 검사라 실행마다
겹치는 파형이 달라진다. 이 수치는 전체 게임의 LUFS나 트루 피크 측정값이 아니다.
화면 밖 실행의 기본 음소거가 결과를 숨기지 않도록 검사 프로세스에서만
`UnfocusedVolumeMultiplier=1.0`을 적용한다. 무음 녹음은 실패로 처리한다.

- `Validate-Project.ps1`: 전체 정적 검사 통과.
- `IndieGameEditor Win64 Development`, `IndieGame Win64 Shipping`: 코드 빌드 통과. 콘텐츠 쿠킹·패키징 검사는 이번 범위에 포함하지 않았다.
- `Run-MissingFloor-Greybox.bat -IGSkipFrontend`: 진행·퍼즐·야간 연출 회귀 검사 통과.
- `Run-CaptureRecoveryReview.ps1`: 1920×1080 연속 30프레임, 접근·포획·방 복귀 확인.
- `Run-ReadmeCapture.ps1`: 실제 입주 경로와 야간 조명에서 새 화면 6장 촬영.
- README: 데스크톱 1200px와 모바일 390px 배치 확인. 본문 이미지 8개, 합계 2,693,646바이트.

재실행 명령은 다음과 같다. 엔진 빌드 후 순서대로 실행한다.

```powershell
pwsh -NoProfile -File Scripts/Run-AudioPresentationProbe.ps1 -FrameRate 60
pwsh -NoProfile -File Scripts/Run-CaptureRecoveryReview.ps1
pwsh -NoProfile -File Scripts/Run-ReadmeCapture.ps1
pwsh -NoProfile -File Scripts/Validate-Project.ps1
```

검사 로그와 원음 녹음은 `Saved/Logs/AudioPresentation-*.log`,
`Saved/AudioPresentation/presentation-mix.wav`에 남는다. 새로 실행하면 해당 녹음을 덮어쓴다.
출시 전에는 [오디오 합격식](MISSING_FLOOR_ACCEPTANCE.md#215-오디오-합격식)에 따라
전체 플레이 음량과 헤드폰·스피커에서의 위치 구분, 초견 플레이의 공포 강도를 확인해야 한다.
