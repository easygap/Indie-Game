# 표면 수정 뒤 현관·관리실 측정

2026-09-17, RTX 3060 8GB / Ryzen 9 7900X / Windows / UE 5.8.

`Run-EntryReview.ps1 -Measure -Quality High -Profile surface-final`로 측정했다. D3D12, 1920×1080, ScreenPercentage 100, Scalability 2, VSync 해제, t.MaxFPS 0이다. PNG 저장은 껐다. 에디터 실행 파일의 `-game` 모드이며 Shipping 빌드 결과는 아니다.

현관·관리실의 기존 9개 고정 시점과 그 사이 전환을 포함한다. 설치된 조끼 근접 시점 3개는 별도 화면 검수에만 들어가므로 이 수치를 조끼 하나의 성능 개선으로 해석하면 안 된다.
