# Implementation Status

## 플레이 가능한 현재 범위

- UE 5.8용 `Prologue_Morning`에서 CH01→CH02→CH03과 두 엔딩을
  끊김 없이 플레이
- CH01 귀환 시 공동현관을 루프 경계로 사용해 1.2초 페이드 후 같은 세션에서 CH02 시작
- CH03는 CH02의 챕터 카드 뒤 같은 세션에서 이어지며,
  `Scripts\RunGame-Chapter3.bat` 또는 `-IGChapterThree`로 바로 시작해
  두 엔딩 선택만 별도로 확인할 수도 있음
- 개발 확인용 `Scripts\RunGame-Chapter2.bat` 및 `-IGChapterTwo` 직접 시작 경로
- 404호(4층) → 공용 복도 → 엘리베이터 → 1층 로비 → 새벽 골목 → 편의점의 수직 동선
- 실물 스캔 소품(Poly Haven CC0)과 절차 모델링 메시, 가상 브랜드 제품 라벨 적용
- 물리 기반 하늘, 히스토그램 자동노출, 볼류메트릭 안개와 공간별 조명
- `WASD` 이동, 마우스 시점, `E` 탭·홀드 상호작용
- 한글 HUD: 목표, 상호작용 프롬프트, 속마음, 홀드 진행 바, 문서 패널, 챕터 카드
- 48kHz 절차적 사운드: 알람, 공간 앰비언스, 형광등, 발소리, 차임, 도어락, 문, 결제음과 매장 징글
- 걷기 헤드밥·호흡 스웨이, 보폭 기반 발소리, 스트레스 기반 심박과 위협압

극중 정사 날짜는 **2024년 7월 26일(금)**이다. 문서의 2026년 표기는
코드 검증일·개발 환경 연도일 수 있으며, 게임 속 날짜와 구분한다.

- 알람 끄기 → 일어나기 → 냉장고 확인 → 지갑 챙기기 → 현관 나가기
- 엘리베이터로 1층 이동 → 골목 통과 → 편의점 입장 → 생수 픽업 → 셀프 계산
- 귀갓길과 빌라 공동현관까지 실제 보행으로 연결
- 가로등 명멸 후 소등, 점장의 존재로 오인하게 하는 창고 소리, 정상 매장 징글과 단일 입장 차임
- 첫 결제 뒤 `2024/07/26(금) 04:44` 영수증을 출력해 CH02의 동일
  영수증 두 장보다 먼저 복선을 심음
- 기상·냉장고·골목·편의점·구매 체크포인트 자동 저장

## CH02 — 두 번째 아침

- CH01의 월드와 상호작용 액터를 재사용하면서 침대 옆에서 기상 루틴을 재시작
- CH02 전용 냉장고·지갑·손전등·생수·문·엘리베이터·계산 상태 재설정
- 404호 동쪽으로 이동한 403호와 미러룸, 잠든 이불 둔덕, 검은 뿔테 안경
- 복도 등이 플레이어의 등 뒤이면서 시야 밖일 때 3초 간격으로 하나씩 소등
- 미러룸 진입 시 문이 크릭 소리만 내며 닫히고, 스탠드 소등 뒤 도어락 음 재생
- 엘리베이터가 누르지 않은 2층에서 멈추고 문을 12cm만 연 채 유지
- 문이 닫히기 직전 캐빈 바닥의 젖은 발자국 공개
- 403호 우편함 속 404호 수취 고지서, 공동현관의 소금·정화수·숟가락 꽂힌 밥과 관리소 메모
- 점장 소리가 사라진 무인 편의점, 0.8초 간격 겹차임, 북측 조명 소등
- CH01보다 반음 낮고 12% 느린 매장 징글
- 결제 전에 놓인 영수증과 결제 후 나오는 동일한 두 번째 영수증
  - 가상 점포 `새벽24 무영로점`, 가상 사업자·대표·주소·전화
  - `2024/07/26(금) 04:44`, `POS-01`, 거래번호
  - 새벽샘물500mL 수량 1, 단가·금액 `1,100원`
  - 과세물품가액 `1,000원`, 부가세 `100원`
  - 마스킹 카드, 가상 매입사, 승인번호, 일시불, 결제금액
  - 80mm 감열지 비율, 고정 열 정렬, 감열 밴딩·압착 주름,
    실제 식별자로 쓸 수 없는 비스캔형 바코드
- 귀환 시 4층 조명 전체 점등 → 404호 위치의 원거리 알람 → 2.2초 페이드 → 「세 번째 아침 — 물이 온다」 카드
- CH02 목표 문구는 `IIGObjectiveProvider`를 통해 전용 디렉터가 HUD에 공급
- CH02 기상·진행 태그는 분리했지만, 로드 코디네이터가 완성되기 전까지 CH02 자동저장은 의도적으로 비활성화

## CH03 — 세 번째 아침

- 4시 44분 알람이 저절로 멎은 뒤 실제 4초 침묵을 거쳐 기상
- 침수된 404호와 복도, 정지한 엘리베이터, 내려갈 때 4층으로 세 번
  되돌아오는 계단, 미완공 5층, 옥상과 물탱크를 하나의 진행 동선으로 구현
- 새벽샘물 병으로 가득 찬 냉장고, 평일 `05:10` 기상·`05:30` 캠프
  집결과 비어 있는 7월 26일 칸이 적힌 플래너 구현
- 어머니의 7월 22일·25일 메시지와 읽지 않은 `7/26 07:02 지운아`를
  필수 조사로 연결하고, 읽기 전에는 404호를 나갈 수 없도록 진행 보호
- 옥상문 작업표에 `03:50` 단수 밸브 잠금·옥상 개방, `03:56` 작업
  연기, 미확인 열쇠 회수·뚜껑 확인, 7월 29일 허위 제출 기록 구현
- 젖은 안경과 작업표를 확인해야 물탱크를 열 수 있는 단서 게이트
- 엔딩 A는 뚜껑을 닫아 알람·차임이 다시 시작되는 반복, 엔딩 B는
  탱크에 들어가지 않고 안경을 수면 위에 놓고 뚜껑을 열어 둔 뒤
  `2024년 8월 16일` 발견·가족 귀환·다음 봄 카드로 끝남
- `R`로 세 번째 아침 재시작, `M`으로 처음부터 돌아가기

## 생활 앰비언트

- 고정 시드와 풀링으로 길고양이 흔적, 돌풍과 마른 잎, 승용차,
  배달함·탑승자·헬멧이 있는 배달 오토바이를 생성
- 거리 밖에서는 잎 시뮬레이션을 중단하고, 활성 사건이 없으면 디렉터의
  프레임 갱신도 끄는 방식으로 비용 제한
- 골목 진입 뒤 첫 큐는 고양이 `0.8초`, 돌풍·잎 `3.4초`, 승용차
  `6.8초`, 그 승용차 뒤 오토바이 `5.4초` 순서
- CH02에서는 고양이 본체 대신 위쪽 소리와 흐트러진 잎만 남기고,
  일부 잎의 방향을 뒤집으며, 보이는 차량의 엔진음이 중간에 끊길 수 있음
- CH02 귀환이 시작되면 남은 차량·고양이·바람·잎 큐를 정지해 원거리
  404호 알람만 남김
