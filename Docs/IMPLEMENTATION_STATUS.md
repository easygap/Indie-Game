## 기존 플레이 빌드에서 확인됐던 범위

아래는 저장소에 남아 있는 구버전 플레이 흐름과 과거 캡처 범위다. 현재
REBIRTH 변경분까지 같은 결과를 낸다는 뜻이 아니며, 현 작업 트리는 엔진
빌드와 런타임을 다시 통과하기 전까지 출시 후보로 취급하지 않는다.

- UE 5.8용 `Prologue_Morning`에서 CH01→CH02→CH03과 두 엔딩을
  끊김 없이 플레이
- CH01 귀환 시 공동현관을 루프 경계로 사용해 1.2초 페이드 후 같은 세션에서 CH02 시작
- CH03는 CH02의 챕터 카드 뒤 같은 세션에서 이어지며,
  `Scripts\RunGame-Chapter3.bat` 또는 `-IGChapterThree`로 바로 시작해
  두 엔딩 선택만 별도로 확인할 수도 있음
- 개발 확인용 `Scripts\RunGame-Chapter2.bat` 및 `-IGChapterTwo` 직접 시작 경로
- 404호(4층) → 공용 복도 → 엘리베이터 → 1층 로비 → 새벽 골목 → 편의점의 수직 동선
- 실물 스캔 소품(Poly Haven CC0)과 절차 모델링 메시, 가상 브랜드 제품 라벨 적용
- 물리 기반 하늘, 히스토그램 자동노출, 볼류메트릭 안개와 공간별 조명
- `WASD` 이동, 마우스 시점, `E` 탭·홀드 상호작용
- 한글 HUD: 목표, 상호작용 프롬프트, 속마음, 홀드 진행 바, 문서 패널, 챕터 카드
- 48kHz 절차적 사운드: 알람, 공간 앰비언스, 형광등, 발소리, 차임, 도어락, 문, 결제음과 매장 징글
- 걷기 헤드밥·호흡 스웨이, 보폭 기반 발소리, 스트레스 기반 심박과 위협압

극중 정사 날짜는 **2024년 7월 26일(금)**이다. 문서의 2026년 표기는
코드 검증일·개발 환경 연도일 수 있으며, 게임 속 날짜와 구분한다.

## CH01 — 첫 번째 아침

공간과 기본 진행은 기존 플레이 흐름을 재사용하지만, 핵심 선택과 진실은
REBIRTH 상태로 연결했다.

- 알람 끄기 → 일어나기 뒤 방 조사는 선택 사항이며, 냉장고·지갑을 보지
  않아도 현관문을 열고 실제 복도 동선으로 나갈 수 있음
- 엘리베이터로 1층 이동 → 골목 통과 → 편의점 입장 → 생수 픽업 → 셀프 계산
- 매대의 A 500mL×2 / B 1L×1 / C 2L×2가 서로 다른 실제 픽업이며,
  결제 전에는 다른 상품을 집어 선택을 바꿀 수 있고 결제한 프로필만
  귀환·복원 상태로 유지
- 지갑을 챙기면 지갑 체크카드, 두고 나오면 후드 주머니 체크카드가
  계산대 프롬프트와 저장 상태에 그대로 반영
- 선택 프로필에 따라 병 수·크기와 얕고 넓은 A, 좁고 높은 B, 넓은 C의
  정적 편의점 봉지 프록시를 결제 뒤 손 프롭에 표시
- 귀갓길과 빌라 공동현관까지 실제 보행으로 연결
- 가로등 명멸 후 소등, 점장의 존재로 오인하게 하는 창고 소리, 정상 매장 징글과 단일 입장 차임
- 첫 결제 영수증은 실제 거래 시각 `2024/07/26(금) 04:31`을 사용하고,
  선택한 상품명·용량·수량·단가·합계를 한 팩터리에서 구성
- 기상·냉장고·골목·편의점·구매 체크포인트 자동 저장
- C 2L×2는 결제 뒤 다른 상호작용을 누르는 동안 봉지 프롭을 48cm
  내려놓고 손을 떼면 원래 운반 위치로 되돌리는 무입력잠금 정적 프록시를
  사용한다. 다만 04:33 음용·재밀봉과 04:43 사다리 앞 최종 배치는 아직
  실제 플레이 이벤트로 연결되지 않았다.

## CH03 — 세 번째 아침

- 4시 44분 알람이 저절로 멎은 뒤 실제 4초 침묵을 거쳐 기상
- 침수된 404호와 복도, 정지한 엘리베이터, 내려갈 때 4층으로 세 번
  되돌아오는 계단, 미완공 5층, 옥상과 물탱크를 하나의 진행 동선으로 구현
- 새벽샘물 병으로 가득 찬 냉장고, 평일 `05:10` 기상·`05:30` 캠프
  집결과 비어 있는 7월 26일 칸이 적힌 플래너 구현
- 어머니의 7월 22일·25일 메시지와 읽지 않은 `7/26 07:02 지운아`를
  선택 조사로 유지하고, 같은 폰 화면의 `04:31 원승인 / 04:44 동일
  승인 중복` 기록을 CH02 P2 생략 시 `DeathOverlay` 대체 출처로 연결
- CH02에서 C3 진실 하나를 남기면 CH03의 플래너(알람), 폰 승인
  기록(시간 오버레이), 어머니 메시지(수색) 중 대응하는 실제 원자료를
  읽어 `NarrativeDebt`를 제거
- 옥상문 작업표에 `03:58` 임시 폐쇄, `04:03` 관리인 재개방,
  `7월 31일 04:00` 합동 확인 기록 구현
- 젖은 안경과 작업표를 확인하지 않아도 물탱크를 먼저 열 수 있으며,
  마지막 선택만 전체 진실 합류 뒤 활성화
- 엔딩 A/B 모두 `2024년 7월 31일 04:00` 공통 발견 카드를 거친 뒤,
  A는 알람·차임이 다시 시작되는 04:44 잔류, B는 가족 귀환 문구로 분기

  몽타주와 인간 음성은 아직 미구현
- `R`로 세 번째 아침 재시작, `M`으로 처음부터 돌아가기
