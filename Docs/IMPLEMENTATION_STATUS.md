# Implementation Status

## 플레이 가능한 현재 범위

- UE 5.8용 `Prologue_Morning` 한 맵에서 CH01과 CH02를 끊김 없이 플레이
- CH01 귀환 시 공동현관을 루프 경계로 사용해 1.2초 페이드 후 같은 세션에서 CH02 시작
- 개발 확인용 `Scripts\RunGame-Chapter2.bat` 및 `-IGChapterTwo` 직접 시작 경로
- 404호(4층) → 공용 복도 → 엘리베이터 → 1층 로비 → 새벽 골목 → 편의점의 수직 동선
- 실물 스캔 소품(Poly Haven CC0)과 절차 모델링 메시, 가상 브랜드 제품 라벨 적용
- 물리 기반 하늘, 히스토그램 자동노출, 볼류메트릭 안개와 공간별 조명
- `WASD` 이동, 마우스 시점, `E` 탭·홀드 상호작용
- 한글 HUD: 목표, 상호작용 프롬프트, 속마음, 홀드 진행 바, 문서 패널, 챕터 카드
- 48kHz 절차적 사운드: 알람, 공간 앰비언스, 형광등, 발소리, 차임, 도어락, 문, 결제음과 매장 징글
- 걷기 헤드밥·호흡 스웨이, 보폭 기반 발소리, 스트레스 기반 심박과 위협압

## CH01 — 첫 번째 아침

- 알람 끄기 → 일어나기 → 냉장고 확인 → 지갑 챙기기 → 현관 나가기
- 엘리베이터로 1층 이동 → 골목 통과 → 편의점 입장 → 생수 픽업 → 셀프 계산
- 귀갓길과 빌라 공동현관까지 실제 보행으로 연결
- 가로등 명멸 후 소등, 점장의 존재로 오인하게 하는 창고 소리, 정상 매장 징글과 단일 입장 차임
- 기상·냉장고·골목·편의점·구매 체크포인트 자동 저장

## CH02 — 두 번째 아침

- CH01의 월드와 상호작용 액터를 재사용하면서 침대 옆에서 기상 루틴을 재시작
- CH02 전용 냉장고·지갑·손전등·생수·문·엘리베이터·계산 상태 재설정
- 404호 동쪽으로 이동한 403호와 미러룸, 잠든 이불 둔덕, 검은 뿔테 안경
- 복도 등이 플레이어의 등 뒤이면서 시야 밖일 때 3초 간격으로 하나씩 소등
- 미러룸 진입 시 문이 크릭 소리만 내며 닫히고, 스탠드 소등 뒤 도어락 음 재생
- 엘리베이터가 누르지 않은 2층에서 멈추고 문을 12cm만 연 채 유지
- 문이 닫히기 직전 캐빈 바닥의 젖은 발자국 공개
- 403호 우편함 속 404호 수취 고지서, 공동현관의 소금·정화수·숟가락 꽂힌 밥과 관리소 메모
- 점장 소리가 사라진 무인 편의점, 0.8초 간격 겹차임, 북측 조명 소등
- CH01보다 반음 낮고 12% 느린 매장 징글
- 결제 전에 놓인 영수증과 결제 후 나오는 동일한 두 번째 영수증
  - 새벽편의점
  - `2026-07-26 04:44`
  - 새벽수 500mL `1,100원`
  - 체크카드 승인 `4482**`
  - 적립 없음
- 귀환 시 4층 조명 전체 점등 → 404호 위치의 원거리 알람 → 2.2초 페이드 → 「세 번째 아침 — 물이 온다」 카드
- CH02 목표 문구는 `IIGObjectiveProvider`를 통해 전용 디렉터가 HUD에 공급
- CH02 기상·진행 태그는 분리했지만, 로드 코디네이터가 완성되기 전까지 CH02 자동저장은 의도적으로 비활성화
