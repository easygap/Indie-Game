## 기존 플레이 빌드에서 확인됐던 범위

아래는 저장소에 남아 있는 구버전 플레이 흐름과 과거 캡처 범위다. 현재
REBIRTH 변경분까지 같은 결과를 낸다는 뜻이 아니며, 현 작업 트리는 엔진
빌드와 런타임을 다시 통과하기 전까지 출시 후보로 취급하지 않는다.

- UE 5.8용 `Prologue_Morning`에서 CH01→CH02→CH03과 두 엔딩을
  끊김 없이 플레이
- CH01 귀환 시 공동현관을 루프 경계로 사용해 1.2초 페이드 후 같은 세션에서 CH02 시작
- CH03는 CH02의 챕터 카드 뒤 같은 세션에서 이어지며,
  `Scripts\RunGame-Chapter3.bat` 또는 `-IGChapterThree`로 바로 시작해
  두 엔딩 선택만 별도로 확인할 수도 있음
- 개발 확인용 `Scripts\RunGame-Chapter2.bat` 및 `-IGChapterTwo` 직접 시작 경로
- 404호(4층) → 공용 복도 → 엘리베이터 → 1층 로비 → 새벽 골목 → 편의점의 수직 동선
- 실물 스캔 소품(Poly Haven CC0)과 절차 모델링 메시, 가상 브랜드 제품 라벨 적용
- 물리 기반 하늘, 히스토그램 자동노출, 볼류메트릭 안개와 공간별 조명
- `WASD` 이동, 마우스 시점, `E` 탭·홀드 상호작용
- 한글 HUD: 목표, 상호작용 프롬프트, 속마음, 홀드 진행 바, 문서 패널, 챕터 카드
- 48kHz 절차적 사운드: 알람, 공간 앰비언스, 형광등, 발소리, 차임, 도어락, 문, 결제음과 매장 징글
- 걷기 헤드밥·호흡 스웨이, 보폭 기반 발소리, 스트레스 기반 심박과 위협압

극중 정사 날짜는 **2024년 7월 26일(금)**이다. 문서의 2026년 표기는
코드 검증일·개발 환경 연도일 수 있으며, 게임 속 날짜와 구분한다.

  귀환·복원 상태로 유지
- 지갑을 챙기면 지갑 체크카드, 두고 나오면 후드 주머니 체크카드가

- 첫 결제 영수증은 실제 거래 시각 `2024/07/26(금) 04:31`을 사용하고,
  선택한 상품명·용량·수량·단가·합계를 한 팩터리에서 구성
- 기상·냉장고·골목·편의점·구매 체크포인트 자동 저장
- C 2L×2는 결제 뒤 다른 상호작용을 누르는 동안 봉지 프롭을 48cm
  내려놓고 손을 떼면 원래 운반 위치로 되돌리는 무입력잠금 정적 프록시를

  사운드로 교체했다.

- 1.8초 기억 경계에서는 손에 든 구매 프롭을 먼저 해제·숨긴 뒤

  나타나지 않고 CH03와 같은 분리 옥상 좌표에 정적 프록시로 만들어졌다가
  장 전환 때 폐기된다. 페이드 중간 저장은 만들지 않으므로 로드는 직전
  4층 안전 체크포인트에서 이 원자적 전환을 한 번 다시 수행한다.
