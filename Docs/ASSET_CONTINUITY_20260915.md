## 참고 자료와 원화

`imagegen`의 내장 이미지 생성 도구로 기존 인물 원화를 입력해 [삼면 참고 이미지](../Content/SourceArt/AI/NarinContinuity_20260915.png)를 만들었다. 얼굴과 목의 연속된 피부색, 턱 아래 윤곽, 회색 티셔츠의 목선을 비교하는 데 썼다. 인물의 얼굴과 근무복은 유지했다.

[농심몰의 제품 표기 사진](https://nongshimmall.com/product/포테토칩-오리지널60g20/2551/)과 기존 포장 앞면을 입력해 [뒷면 인쇄 원화](../Content/SourceArt/Labels/Store/RetailPackagingBack.png)도 생성했다. 감자칩·새우스낵·콘스낵·초코비스킷 네 칸을 Blender의 각 포장에 매핑하고 게임용 텍스처로 구웠다. 사진은 관찰과 생성 입력에만 사용했으며 게임에 원본 사진을 넣지는 않았다. 사용 모드, 입력 자료, 실제 생성 프롬프트는 [생성 기록](../Content/SourceArt/AI/AssetContinuity_20260915.json)에 남겼다.

[농심 사발면 사진](https://brand.nongshim.com/bowlnoodle/main/index)에서는 낮은 흰 용기와 인쇄 뚜껑을 확인했다. 흰 옆면 자체는 오류가 아니어서 유지했다. [GS25 매장 사진](https://www.daangn.com/kr/local-profile/gs25-%EB%A7%88%EC%82%B0%EB%B0%98%EC%9B%94%EC%A4%91%EC%95%99%EC%A0%90-24%EC%8B%9C%EC%98%81%EC%97%85-g2yb7z5eo9k4/)에서 확인했던 품목별 구획과 앞줄 정돈도 유지했다.

온수기는 [NS-3000B 판매 사진](https://m.icekhan.com/product/전기온수기-ns-3000b-핫워터-디스펜서-업소용-온수기-수동온수기-핫온수기/8160/)의 코크와 외부 물받이 구조를 참고했다. 게임 모델의 치수는 해당 제품의 실측값이 아니다. 기존 취식대에 맞는 소형 본체로 만들었다.

## 확인한 문제와 수정

| 대상 | 확인한 문제 | 수정 |
| --- | --- | --- |

| 비스킷 상자 | 앞면 외에는 흰 민무늬 | 뒷면·윗면·옆면 인쇄와 갈색 접힘 면 적용 |

| 뒷골목 | 바닥과 끝벽 사이, 샛길 벽 끝 모서리에 하늘이 보이는 틈 | 끝벽 안쪽까지 바닥 폭 확장, 10×10cm 모서리 연결 |

| 전자레인지·진열 선반 | 지지면, 크기, 겹침 재확인 | 이번 검수에서 추가 교체가 필요한 문제는 확인하지 못함 |

## 재현 방법

`Run-RetailReview.ps1 -Audit`는 기본 일곱 장에 나린의 좌우·중거리, 상품 뒷면, 취식대, 스탠드, 뒷골목 끝을 더해 실제 게임 화면 열네 장을 저장한다. 성능 측정과 확대 검수는 별도 실행이다. 검수용 카메라를 추가해도 기존 성능 측정 동선은 바뀌지 않는다.

```powershell
pwsh -NoProfile -File Scripts/Run-RetailReview.ps1 -Audit -Profile ContinuityHigh
pwsh -NoProfile -File Scripts/Run-GameplayRealismProbe.ps1 -FrameRate 60
pwsh -NoProfile -File Scripts/Validate-Project.ps1
```

모델 연결부 검사는 Blender에서 `Scripts/blender/check_clerk_neck.py`를 실행한다. 실제 연결된 정점의 UV 양쪽 색을 대조하고, 목 주변의 열린 변과 세 면 이상이 붙은 변을 검사한다. 화면 확인을 대신하는 검사는 아니다.

반복 상품과 가격표는 1,318개 인스턴스, 27개 묶음이다. 포장 앞뒤는 같은 재질에 구워 추가 그리기 호출을 만들지 않았다. 가까운 인물과 상품의 기존 LOD와 텍스처 스트리밍을 유지한다.

## 검증 결과

- UE 5.8 에디터 개발 빌드 성공. 수정한 메시 6종과 해당 텍스처를 게임에 반입했다.
- 목 연결부의 비정상 변 0개. UV 경계 정점 58개의 sRGB 채널 차이 95백분위가 0.00784였다. 인물은 15,184삼각형이며 기존 4K 텍스처 구성을 유지했다.
- 매장 확대 검수 14개 시점과 기존 동선 12개 시점을 1920×1080 D3D12 화면으로 확인했다. 기존 동선은 세 샛길과 편의점 출입문을 실제 캐릭터 이동으로 통과한다.
- 60Hz 조작·상호작용 검사 통과. 달리기 제동, 문틀 통과, 벽 뒤 사물 제외, 닫힌 문 뒤 포획 차단, 인물 LOD와 포획 자세를 확인했다.
- 입주 시작 경로 검사 통과. 소품 7개, 자유로운 조사 순서와 배송 분기가 유지된다.
- `Validate-Project.ps1` 통과. 재질 참조, 표면 투영, 겹친 면, 조명 위치, 소품 크기와 README 검사를 포함한다.
- README의 정지 화면과 낮 동선 GIF를 새 캡처로 갱신하고 표시용 축소본도 다시 만들었다.
