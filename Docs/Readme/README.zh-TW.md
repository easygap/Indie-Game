# Missing Floor

退回的包裹上，哥哥的地址寫著月光公寓501室。
但這棟公寓，只有四層樓。

為了尋找失聯的哥哥，侑潭搬進403室。她向鄰居打聽消息，翻找哥哥留下的東西。凌晨四點半，天花板上開始傳來敲擊聲。

以韓國老舊住宅為舞台的第一人稱恐怖遊戲。Windows · 單人遊戲 · 開發中。

[下載 Windows 測試版](https://github.com/easygap/Missing-Floor/releases/download/v0.2.4/MissingFloor-0.2.4-Windows.zip) · [觀看預告片](https://github.com/easygap/Missing-Floor/releases/download/v0.2.3/MissingFloor-Trailer.mp4)

## 到這裡，找哥哥

退回的包裹、舊語音留言，以及鄰居偶然提起的往事，都是尋人的線索。整理房間，到巷子對面的便利商店問問，再去管理室翻翻帳本、看看監視器。那些紀錄，有些地方對不起來。

![還沒整理好的403室](../Media/readme/game-bedroom.webp)

![公寓前的巷弄](../Media/readme/game-alley.webp)

## 凌晨四點半，小心別出聲

夜裡，有東西在走廊遊蕩，聽見聲音就會靠過來。奔跑的腳步聲、突然開門的動靜，都可能讓它找到你。慢慢開門，從它身邊經過時，先憋住呼吸。

被抓到後，你會在自己的房間醒來。找到的線索會留下，但時間不會倒退。

![熄燈後的走廊](../Media/readme/game-corridor-night.webp)

貼著牆聽聲音，比對文件，查看電表。白天可按`Tab`翻閱調查紀錄；不知道下一步該怎麼做時，按`H`查看提示。

## 測試版 0.2.4

將 ZIP 檔完整解壓縮，再執行`MissingFloor.exe`。同一個資料夾裡的`Engine`和`IndieGame`也要保留。遊戲會自動儲存進度。[執行說明](../PLAYING.md)目前為韓文。

遊戲支援韓文、英文、日文、簡體中文與繁體中文。第一次啟動會使用 Windows 的顯示語言，之後可在設定中切換。

## 操作

| 按鍵 | 操作 |
|---|---|
| WASD / 滑鼠 | 移動 / 轉動視角 |
| 左 Shift / C / Space | 奔跑 / 蹲下 / 跳躍 |
| E / 長按 E | 調查、開門 / 慢慢開門、貼牆傾聽 |
| Q | 敲擊 |
| 左 Ctrl | 憋氣 |
| F | 手電筒 |
| Tab / H | 調查紀錄（白天）/ 提示 |
| Esc / F1 / F10 | 暫停 / 操作說明 / 設定 |

可在設定中調整難度、字幕、聲音方向提示、鏡頭晃動與畫面質感，也能關閉追逐。麥克風輸入是選用功能，預設關閉。

若遇到問題，請到[Issues](https://github.com/easygap/Missing-Floor/issues)描述出現問題的場景，並附上 Windows 版本與顯示卡型號。
