# The Missing Floor

韓国の古いアパートを舞台に、行方不明の兄を探す一人称視点のホラーゲームです。
住人に話を聞き、部屋や廊下を調べて手がかりを集めます。
夜になると音に反応する敵が現れるため、ドアを開けるときも油断できません。

Windows PC · 1人用 · ゲーム内の対応言語：韓国語のみ · 開発中

[Windows版をダウンロード](https://github.com/easygap/Indie-Game/releases/download/v1.0.0-test.20260922/MissingFloor-Windows-20260922.zip) · [操作方法](#操作方法)

![古いアパートを背景に、韓国語のメニューが並ぶタイトル画面。](../Media/readme/title-menu-first-run-1080.webp)

## あらすじ

主人公のユダムは、連絡が途絶えた兄を探して403号室に引っ越してきます。
返送された荷物に書かれていた兄の住所は501号室。でも、この建物は4階までしかありません。

引っ越して最初の夜。午前4時半、天井の向こうからノックの音が聞こえてきます。

![引っ越しの段ボールや生活用品が置かれたユダムの部屋。](../Media/readme/game-bedroom.webp)

## 近所を歩いて手がかりを探す

住人との会話や部屋に残された物から、兄の行方をたどっていきます。

## 調べて、聞いて、謎を解く

壁に耳を当てて音を聞いたり、管理室の書類や防犯カメラを確認したりして手がかりを探します。電気メーターも調べてみてください。
集めた手がかりは昼間に `Tab` で読み返せます。進めなくなったら `H` でヒントを確認できます。

## ダウンロードと起動方法

現在ダウンロードできるのは **2026年9月22日のテスト版**です。**ゲーム本編は韓国語のみ対応**しています。メニュー、会話、手がかりの文章も韓国語です。

1. [Windows版のZIPファイル（727MB）](https://github.com/easygap/Indie-Game/releases/download/v1.0.0-test.20260922/MissingFloor-Windows-20260922.zip)をダウンロードします。
2. すべてのファイルを展開し、`IndieGame.exe` を起動します。
3. **게임 시작**（ゲーム開始）を選んでください。続きから遊ぶ場合は **이어하기** を選びます。

進行状況は自動でセーブされます。実行ファイルと同じ場所にある `Engine` と `IndieGame` フォルダーは移動しないでください。

Windows 11、Ryzen 9 7900X、RTX 3060、メモリ32GBのPCで動作を確認しています。最低動作環境はまだ確定していません。

DLLが見つからないと表示された場合は、ZIPをすべて展開したか確認し、`Engine/Extras/Redist/en-us/vc_redist.x64.exe` を実行してください。動作が重い場合は、解像度や画質設定を下げてみてください。

## 操作方法

`WASD` で移動、マウスで視点を動かします。`E` で物を調べたりドアを開けたりできます。ドアの前で長押しすると、静かに開けられます。

コントローラーにも対応しています。キーやボタンの割り当ては設定から変更できます。操作説明は `F1`、またはコントローラーの方向キー上で再表示できます。

<details>
<summary>操作一覧</summary>

| キー | 操作 |
|---|---|
| `W A S D`・マウス | 移動・視点操作 |
| `左Shift`・`C`・`Space` | 走る・しゃがむ・ジャンプ |
| `E` | 調べる・ドアを開ける |
| `E` 長押し | 静かにドアを開ける・壁越しに音を聞く |
| `Q`・`左Ctrl` | ノックする・息を止める |
| `F` | 懐中電灯 |
| `F1` | 目標と操作説明 |
| `Tab`・`H` | 記録を読む（昼間）・ヒント |
| `← →`・マウスホイール | 資料のページをめくる |
| `Esc`・`F10` | 一時停止・アクセシビリティ設定 |

</details>

## 難易度と遊びやすさの設定

追いかけられるのが苦手な方は、`F10` から **추격 없음**（追跡なし）を選んでください。敵に捕まることなく、謎解きや物語を最後まで進められます。イージー・ノーマル・ハードもあり、プレイ中に変更できます。

字幕の大きさ、背景の濃さ、表示時間を調節できます。音のする方向を画面に表示したり、ノックをコントローラーの振動で知らせたりする設定もあります。画面の揺れや点滅を抑えたり、ボタンを押し続けずに操作できるようにしたり、BGMと環境音の音量を別々に調節したりすることもできます。

![字幕の大きさや背景、表示時間を調節する韓国語の設定画面。](../Media/readme/settings-accessibility-20260922.webp)

暗い場面、突然敵が現れる演出、大きな音が含まれます。プレイ前に音量と明るさを調節してください。
