# Missing Floor

返送されてきた荷物に書かれた兄の住所は、月光ヴィラの501号室。
けれど、この建物は4階までしかない。

連絡の途絶えた兄を捜し、403号室に引っ越してきたユダム。住人に話を聞き、兄の残したものを調べていくうちに、最上階の天井からノックが聞こえるようになる。時刻は、午前4時半。

韓国の古い集合住宅を舞台にした一人称ホラーゲームです。Windows向け・1人用・開発中。

[Windows体験版をダウンロード](https://github.com/easygap/Missing-Floor/releases/download/v0.2.2/MissingFloor-0.2.2-Windows.zip) · [トレーラーを見る](https://github.com/easygap/Missing-Floor/releases/download/v0.2.2/MissingFloor-Trailer.mp4)

## この町で、兄を捜す

返送された荷物と、古い留守番電話のメッセージ。わずかな手がかりを頼りに、隣人やコンビニの店員に兄のことを尋ねます。管理室の帳簿や監視カメラの記録には、食い違う情報が残されています。

![荷ほどきの途中の403号室](../Media/readme/game-bedroom.webp)

![ヴィラの前の路地](../Media/readme/game-alley.webp)

## 午前4時半、物音を立てないで

夜の廊下には、音を頼りに近づいてくる何かがいます。走る足音も、勢いよく開けたドアの音も、居場所を知らせてしまいます。ドアはゆっくり開け、近くを通るときは息を止めてください。

捕まると、自分の部屋で目を覚まします。見つけた手がかりは残りますが、時刻は戻りません。

![明かりの消えた廊下](../Media/readme/game-corridor-night.webp)

壁に耳を当て、書類を読み比べ、電気メーターを確かめる。昼間は`Tab`で調査記録を読み返せます。行き詰まったら`H`でヒントを確認してください。

## 体験版 0.2.2

ZIPファイルをすべて展開し、`MissingFloor.exe`を起動してください。同じフォルダーの`Engine`と`IndieGame`も必要です。進行状況は自動で保存されます。[起動ガイド](../PLAYING.md)は韓国語です。

ゲーム内の対応言語は韓国語・英語・日本語・簡体字中国語・繁体字中国語です。初回はWindowsの表示言語に合わせて起動し、設定から変更できます。

## 操作

| キー | 操作 |
|---|---|
| WASD / マウス | 移動 / 視点移動 |
| 左Shift / C / Space | 走る / しゃがむ / ジャンプ |
| E / E長押し | 調べる・開ける / ドアをゆっくり開ける・壁に耳を当てる |
| Q | ノック |
| 左Ctrl | 息を止める |
| F | 懐中電灯 |
| Tab / H | 調査記録（昼間）/ ヒント |
| Esc / F1 / F10 | ポーズ / 操作一覧 / 設定 |

難易度のほか、字幕、音の方向表示、カメラの揺れ、画面の質感を調整できます。追跡なしの設定もあります。マイク入力は任意で、初期設定ではオフです。

不具合は[Issues](https://github.com/easygap/Missing-Floor/issues)へ。Windowsのバージョン、グラフィックカード、問題が起きた場面を添えてください。
