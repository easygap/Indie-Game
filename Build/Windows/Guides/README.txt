Missing Floor - Windows {EDITION_EN} {VERSION} ({DATE_ISO})
한국어 안내는 시작하기.txt에 있습니다.

Extract the whole ZIP, then run MissingFloor.exe.
Keep the Engine and IndieGame folders next to the executable.
You don't need to install Unreal Engine or Visual Studio.

WASD: move / Mouse: look around / Left Shift: sprint / C: crouch / Space: jump
E: examine or interact / Hold E: open doors quietly or listen through walls
Q: knock / Left Ctrl: hold your breath / F: toggle flashlight
Tab: open journal (daytime) / H: hint / Arrow keys or mouse wheel: turn pages
F1: objectives and controls / F10: difficulty and accessibility / Esc: pause
Controllers are supported. You can remap keys and buttons in Settings.

Progress is saved automatically. Select Continue to resume your game.
If being chased is too much, press F10 and set the difficulty to No Chase.
The game starts in your Windows language.
To change it, go to Settings > General > Language.

Want to help test? Open the 테스트 도구 (Test Tools) folder and read:
https://github.com/easygap/Missing-Floor/blob/main/Docs/TESTING.md

About the game: https://github.com/easygap/Missing-Floor
Report a problem: https://github.com/easygap/Missing-Floor/issues

Missing Floor Windows {EDITION_JA} {VERSION}（{DATE_JA}）

Engine 和 IndieGame 文件夹要和 MissingFloor.exe 放在同一位置。

WASD：移动 / 鼠标：环顾 / 左 Shift：奔跑 / C：蹲下 / Space：跳跃
